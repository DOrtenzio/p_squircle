7.1 Проблема: множення поліномів

У ML-KEM основні операції включають множення поліномів у кільці \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\).

Наївне множення

Два поліноми степеня \(n-1\) множаться шкільним алгоритмом зі складністю \(O(n^2)\).

  • Для \(n = 256\): близько \(256^2 = 65536\) множень для одного добутку.
  • У ML-KEM-768 (\(k=3\)) одна операція Encaps потребує десятків поліноміальних множень → мільйони множень наївним методом.

З NTT

Складність знижується до \(O(n \log n)\):

\[ 256 \cdot 8 = 2048 \text{ операцій на добуток} \]

Прискорення: ~32×. На оптимізованому обладнанні ML-KEM-768 виконується менш ніж за 1 мс.

7.2 Перетворення Фур'є та DFT

Теорема про згортку

Перетворення Фур'є перетворює згортку (як множення поліномів) на поточкове множення:

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

Процедура:

  1. Обчислити \(\hat{f} = \text{DFT}(f)\) та \(\hat{g} = \text{DFT}(g)\)
  2. Перемножити поточково: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. Виконати обернене перетворення: \(h = \text{DFT}^{-1}(\hat{h})\)

Якщо DFT та DFT-1 коштують \(O(n \log n)\) (через БПФ), все множення коштує \(O(n \log n)\).

Швидке перетворення Фур'є (БПФ)

Алгоритм Кулі-Тьюкі (1965) обчислює DFT, використовуючи рекурсивну структуру:

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{парні}}], \; \text{DFT}[f_{\text{непарні}}]\right) \text{ з коефіцієнтами повороту} \]

Проблема: Стандартне БПФ використовує комплексні числа (з плаваючою комою), що вносить помилки округлення та непостійний час, роблячи його непридатним для криптографії.

7.3 NTT: DFT у модульному світі

Ідея

NTT (Числове теоретичне перетворення) — це DFT, застосована до \(\mathbb{Z}_q\) замість \(\mathbb{C}\). Замість комплексних коренів з одиниці \(e^{2\pi i k/n}\) використовуються примітивні корені з одиниці в \(\mathbb{Z}_q\).

Примітивні корені з одиниці за модулем q

Елемент \(\omega \in \mathbb{Z}_q\) є примітивним коренем \(n\)-го степеня з одиниці, якщо:

\[ \omega^n \equiv 1 \pmod{q} \quad \text{і} \quad \omega^k \not\equiv 1 \pmod{q} \text{ для } 0 < k < n \]

Необхідна умова: \(n \mid (q-1)\) (тобто \(n\) ділить \(q-1\)).

У ML-KEM:

  • \(q = 3329\), \(n = 256\)
  • Перевірка: \(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • Отже, існують корені 256-го степеня з одиниці за модулем 3329.
  • Примітивний корінь, що використовується в FIPS 203: \(\omega = 17\) (оскільки \(17^{128} \equiv -1 \pmod{3329}\), корінь, що використовується для негациклічного NTT, дорівнює \(\zeta = 17\)).

Визначення NTT

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

Обернене NTT:

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

де \(n^{-1} = 256^{-1} \bmod 3329 = 3303\).

Ключові властивості

  • Точне: немає помилок округлення, все в \(\mathbb{Z}_q\)
  • Ефективне: \(O(n \log n)\) як БПФ
  • Постійний час: може бути реалізоване без розгалужень на секретних даних (стійкість до побічних каналів)

7.4 NTT у ML-KEM

Негациклічне NTT

У ML-KEM редукція виконується не за модулем \(X^n - 1\) (циклічна), а за модулем \(X^n + 1\) (негациклічна). У негациклічній згортці "загорнуті" члени змінюють знак. Це потребує варіанту класичного NTT зі скоригованими коефіцієнтами повороту.

NTT у FIPS 203 застосовує попереднє скручування зі степенями \(\zeta = 17\):

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{перед класичним NTT} \]

Операції ML-KEM у домені NTT

Після перетворення поліноми перебувають у домені NTT. Операції стають елементарними:

Операція У домені NTT
Множення \(f \cdot g\) для кожного \(i\) \(\hat{f}_i \cdot \hat{g}_i\)
Додавання \(f + g\) для кожного \(i\) \(\hat{f}_i + \hat{g}_i\)
Множення матриці на вектор \(A \cdot s\) \(k^2\) поточкових множень та \(k^2\) поточкових додавань

Публічний ключ \(A\) генерується та зберігається вже в домені NTT, уникаючи перерахунку NTT щоразу.

Повний потік KeyGen

зерно 
  │
  ├──► SHAKE128 ──► A_hat (вже в NTT)
  │
  └──► Біноміальне семплювання ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          Публічний ключ (t_hat)

Вихід t_hat — це публічний ключ (вже в NTT). Уникається NTT-1 для \(t\).

7.5 Спрощений числовий приклад

Використовуємо \(n = 4\), \(q = 5\), \(\omega = 2\) (корінь 4-го степеня з 1 за модулем 5: \(2^4 = 16 \equiv 1 \pmod 5\)).

Поліноми:

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

NTT від f:

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

NTT від g: \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\). Для \(i=0\): \(4 \equiv 4\); для \(i \neq 0\): сума коренів \(= 0\).

Поточкове множення: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\).

Обернене NTT від \(\hat{h}\): дає добуток \(f \cdot g \bmod (X^4-1, 5)\).

Примітка: цей приклад використовує редукцію за модулем \(X^4-1\) (циклічну). ML-KEM використовує \(X^n+1\) (негациклічну) з варіантом, описаним у розділі 7.4.

7.6 Реалізація

Псевдокод Кулі-Тьюкі для NTT

def ntt(f, q, omega):
    """
    Ітеративне NTT in-place (Кулі-Тьюкі).
    f: список з n коефіцієнтів у Z_q
    q: простий модуль
    omega: примітивний корінь n-го степеня з одиниці mod q
    """
    n = len(f)
    # перестановка bit-reversal
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # операції "метелик"
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

Еталонна реалізація

FIPS 203 визначає точну реалізацію NTT та попередньо обчислену таблицю коренів \(\zeta^{br(i)}\) (де \(br\) — перестановка бітового обернення).

Оптимізовані реалізації на асемблері/SIMD доступні в:

  • liboqs (C з AVX2)
  • pqclean (переносимий C)
  • kyber еталонна реалізація (C)
