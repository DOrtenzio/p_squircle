9.1 보안 모델

IND-CPA (선택 평문 공격 아래 구별 불가능성)

이 모델에서 공격자는:

  1. 공개 키 \(ek\)를 받음
  2. 두 메시지 \(m_0, m_1\)를 선택
  3. 그 중 하나(무작위 선택)의 암호문을 받음
  4. 어떤 메시지가 암호화되었는지 추측해야 함

방식은 \(\Pr[\text{추측}] \leq 1/2 + \text{negl}(\lambda)\)이면 안전합니다.

K-PKE(기본 암호화 구성 요소)는 MLWE 가정 하에 IND-CPA입니다.

IND-CCA2 (적응적 선택 암호문 공격 아래 구별 불가능성)

CPA와 같지만, 공격자는 도전 암호문을 제외한 모든 암호문에 대해 복호화 오라클을 질의할 수 있습니다. 이 모델은 공격자가 임시로 구성된 메시지를 보내고 응답을 관찰하는 실제 공격(Bleichenbacher와 같은)을 포착합니다.

ML-KEM은 IND-CCA2입니다. 이는 TLS나 SSH와 같은 실제 프로토콜에서 안전한 KEM에 요구되는 수준입니다.

ROM vs. QROM

보안 증명은 해시 함수에 대한 이상화된 모델을 사용합니다:

  • ROM (무작위 오라클 모델): 해시는 완벽한 무작위 오라클입니다.
  • QROM (양자 무작위 오라클 모델): 양자 공격자는 오라클을 중첩 상태로 질의할 수 있습니다.

ML-KEM에 사용된 FO(후지사키-오카모토) 변환에 대한 현대적 증명은 QROM에서의 보안을 보장하며, 이는 양자 공격자에 대해 필수적입니다.

9.2 MLWE의 난이도 측정

공격 비용으로서의 보안

MLWE가 어렵다는 절대적 증명은 존재하지 않습니다. 보안은 알려진 최고의 공격 알고리즘의 비용을 계산하여 추정됩니다. \(\lambda\)비트 보안은 공격에 약 \(2^\lambda\) 연산이 필요함을 의미합니다.

매개변수

난이도는 다음에 따라 달라집니다:

  • \(n = 256\) (다항식 크기, 고정)
  • \(k \in \{2, 3, 4\}\) (모듈 차원)
  • \(q = 3329\) (소수 모듈로)
  • \(\eta \in \{2, 3\}\) (잡음 진폭)

격자 추정기

표준 도구는 Albrecht 등의 격자 추정기(Lattice Estimator)입니다. ML-KEM-768의 경우:

공격 추정 비용 (비트)
원시 공격 (BKZ) ~178비트
이중 공격 ~175비트
조합 공격 > 200비트

보안 여유는 128비트 고전/양자 목표에 비해 넉넉합니다.

9.3 격자에 대한 주요 공격

BKZ (Block Korkine-Zolotarev)

짧은 벡터를 찾는 최고의 일반 알고리즘입니다. 격자를 크기 \(\beta\)의 블록으로 나누고 지역적으로 SVP를 해결합니다. 복잡도: \(2^{O(\beta \log \beta)}\). ML-KEM-768의 경우 \(\beta \approx 430\).

원시 공격 (uSVP)

MLWE를 공개 키와 암호문을 포함하는 확장 격자의 짧은 벡터 문제로 축소합니다. 비밀 벡터 \((\mathbf{s}, \mathbf{e}, -1)\)는 BKZ가 찾으려는 짧은 벡터가 됩니다.

이중 공격

통계를 통해 MLWE 샘플을 균일한 샘플과 구별하기 위해 이중 격자의 짧은 벡터를 활용합니다. 구별자를 수행하기 위해 이중 격자에서 많은 짧은 벡터를 구성합니다.

q = 3329의 선택

소수이고 특별한 대수 구조가 없어 특정 대수 공격을 방지합니다. 악용될 수 있는 작은 인수나 간단한 관계가 존재하지 않습니다.

9.4 NIST 보안 수준

NIST는 5개 수준을 정의했습니다. ML-KEM은 수준 1, 3, 5를 포괄합니다:

방식 NIST 수준 고전적 보안 양자 보안
ML-KEM-512 1 (AES-128) ~118비트 ~100비트
ML-KEM-768 3 (AES-192) ~178비트 ~164비트
ML-KEM-1024 5 (AES-256) ~230비트 ~218비트

권장: ML-KEM-768은 대부분의 용도에 최적의 보안/성능 균형을 제공합니다. ML-KEM-1024는 매우 높은 중요도 시스템용으로 예약됩니다.

9.5 다른 PQC 방식과의 비교

표준화된 양자 내성 KEM (NIST 2024)

방식 수학적 기반 공개 키 암호문
ML-KEM-768 MLWE (격자) 1184 B 1088 B
BIKE 오류 정정 코드 ~1541 B ~1573 B
HQC 오류 정정 코드 ~2249 B ~4522 B
Classic McEliece Goppa 코드 ~261 KB 128 B

고전 암호화와의 비교

방식 공개 키 양자 보안
RSA-3072 384 B ❌ 취약
ECDH X25519 32 B ❌ 취약
ML-KEM-768 1184 B ✅ 164+ 비트

주요 비용은 더 큰 크기(ECDH 대비 ~37배)이지만, 현대 TLS 핸드셰이크에 여전히 허용됩니다.

9.6 부채널 및 안전한 구현

올바른 구현도 실행 시간(시간 측정 공격)이나 전력 소비를 통해 정보를 누출하면 취약할 수 있습니다.

일정 시간 (CT)

모든 연산은 비밀 데이터와 무관하게 일정한 시간을 가져야 합니다. Decaps의 중요한 예:

// 안전하지 않음 (가변 시간):
if (memcmp(c, c_prime, len) == 0) {
    K = K_good;
} else {
    K = K_reject;
}

// 안전함 (일정 시간):
uint8_t mask = ct_memcmp(c, c_prime, len); // 같으면 0xFF, 다르면 0x00
K = ct_select(mask, K_good, K_reject);     // 분기 없는 CT 선택

ML-KEM의 CT 중요 영역

  • \(B_\eta\) 샘플링: 조건부 분기 없는 비트 합산.
  • NTT: 결과가 변경되지 않더라도 나비 연산은 항상 실행되어야 함.
  • 암호문 검증: ct_memcmp 사용.

참조 구현

  • pqclean: 이식 가능한 CT 구현.
  • liboqs: CT 속성이 검증된 AVX2 최적화.
