3.1 양자 컴퓨터: 기본 개념

큐비트 vs. 고전 비트

고전 비트는 0 또는 1입니다. 큐비트는 중첩 상태에 있을 수 있습니다: \(|0\rangle\)과 \(|1\rangle\)의 선형 결합입니다.

\[ |\psi\rangle = \alpha|0\rangle + \beta|1\rangle \qquad |\alpha|^2 + |\beta|^2 = 1 \]

측정 전에 큐비트는 "0이면서 1"입니다. 측정 후에는 0(확률 \(|\alpha|^2\)) 또는 1(확률 \(|\beta|^2\))로 붕괴됩니다.

비유: 공중에 던져진 동전이 앞면과 뒷면을 동시에 나타내는 것과 같습니다. 당신이 볼 때만 둘 중 하나로 결정됩니다.

얽힘과 간섭

  • 얽힘: 두 큐비트는 서로 상관관계를 가질 수 있어, 하나를 측정하면 다른 하나가 즉시 결정됩니다.
  • 양자 간섭: "잘못된" 계산 경로는 상쇄되고(파동이 소멸하는 것처럼), "올바른" 경로는 증폭됩니다.

양자 알고리즘은 간섭을 활용하여 올바른 답을 증폭하고 잘못된 답을 억제합니다.

양자 병렬성

\(n\)개의 큐비트로 \(2^n\)개의 상태를 동시에 표현할 수 있습니다. 하지만 측정은 단일 상태만 반환합니다 → 요령은 간섭이 오직 올바른 답만 살아남도록 하는 알고리즘을 구성하는 것입니다.

3.2 쇼어 알고리즘

\(n\)을 인수분해하기 위한 알고리즘 개요

  1. 입력: 합성수 \(n\)
  2. 초기화: \(1 < a < n\)이고 \(\gcd(a,n)=1\)인 무작위 \(a\) 선택
  3. 양자 준비: \(0\)부터 \(2^k-1\)까지의 균일 중첩 레지스터 준비
  4. 오라클: \(f(x) = a^x \bmod n\)을 병렬로 계산 (중첩)
  5. QFT: 첫 번째 레지스터에 양자 푸리에 변환 적용
  6. 측정: 레지스터를 측정하여 주기 \(r\)과 상관된 값 획득
  7. 고전: 연분수 알고리즘을 사용하여 \(r\) 추정
  8. 검증: \(r\)이 짝수이고 \(a^{r/2} \not\equiv -1 \pmod n\)인 경우:
    • \(\gcd(a^{r/2} - 1, n)\)과 \(\gcd(a^{r/2} + 1, n)\) 계산
    • 이들은 \(n\)의 자명하지 않은 인수입니다
  9. 반복: 실패하면 새로운 \(a\)로 2단계로 돌아갑니다

참고: 양자 핵심(3-5단계)은 QFT의 구성적/파괴적 간섭을 활용하여 함수 \(f(x)\)의 주기 \(r\)을 다항식 시간에 찾습니다.

3.3 RSA, DH, ECC에 미치는 영향

방식 보안 기반 쇼어에 취약?
RSA 소인수분해 예
DH (mod \(p\)) \(\mathbb{Z}_p^*\)의 이산 로그 예
ECDH / ECDSA ECDLP (타원곡선 이산 로그) 예
ML-KEM (MLWE) 격자 기반 문제 알려진 효율적 알고리즘 없음
AES-256 의사 난수 치환 그로버만 (아래 참조)

쇼어는 아벨 군에서 주기성을 찾는 것과 같은 구조화된 문제를 해결합니다. 소인수분해와 이산 로그(타원곡선 포함)는 정확히 이 구조를 가집니다. 격자 기반 문제는 그렇지 않습니다.

3.4 그로버: 대칭키 암호화에 대한 위협

그로버 알고리즘(1996)은 비구조화 검색에서 제곱근 가속을 제공합니다:

  • \(2^k\)개의 가능성 중 키 찾기 (고전): \(O(2^k)\) 시도
  • 그로버 사용 시: \(O(2^{k/2})\) 시도

실제 영향:

키 고전적 보안 양자 내성 보안 (그로버)
AES-128 128비트 64비트 → 불충분
AES-256 256비트 128비트 → 여전히 안전
SHA-256 256비트 128비트 → 안전
SHA3-256 256비트 128비트 → 안전

이 때문에 NIST는 양자 내성 맥락에서 AES-128이 아닌 AES-256을 권장합니다.

3.5 양자 컴퓨터의 최신 기술 현황 (2024–2025)

현재 양자 컴퓨터는 NISQ (잡음이 있는 중간 규모 양자)입니다: 수십에서 수백 개의 물리적 큐비트를 가지지만 오류율이 높습니다.

쇼어로 RSA-2048을 깨는 데 필요한 것:

  • ~4000개의 완벽한 논리적 큐비트
  • 또는 양자 오류 수정을 포함한 ~400만 개의 물리적 큐비트

현재 최고 시스템(Google Willow, IBM Heron 등)은 ~100-1000개의 고충실도 물리적 큐비트를 가지지만, 필요한 규모에는 아직 멀었습니다.

NIST 추정: 암호학적으로 유의미한 양자 컴퓨터는 10~15년 내에 등장할 수 있으며, 양방향으로 상당한 불확실성이 있습니다.

3.6 지금 수집하고 나중에 복호화

암호학적으로 유의미한 양자 컴퓨터가 아직 존재하지 않더라도, 오늘 존재하는 구체적인 위협이 있습니다:

공격자는 지금 암호화된 통신을 수집하고(복호화할 수 없더라도), 충분히 강력한 양자 컴퓨터를 가지게 되면 미래에 복호화할 수 있습니다.

이 공격은 "지금 수집, 나중에 복호화"(HNDL) 또는 저장-지금-나중에-복호화로 알려져 있습니다.

위험에 처한 대상:

  • 긴 비밀 수명을 가진 외교 및 군사 통신
  • 수십 년간의 기밀 요구사항이 있는 의료, 금융, 법률 데이터
  • 산업 기밀 및 지적 재산권

언제 전환해야 할까?

데이터가 충분히 강력한 양자 컴퓨터가 등장하기까지 남은 년수보다 더 오래 비밀로 유지되어야 한다면, 지금 전환해야 합니다.

이것이 NIST가 2024년에 ML-KEM(FIPS 203)을 표준화한 주요 이유이며, NSA, ENISA, ANSSI와 같은 기관들이 높은 중요성 시스템에 대해 즉각적인 전환을 권장하는 이유입니다.
