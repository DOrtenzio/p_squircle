07 – NTT (수론적 변환)

7.1 문제: 다항식 곱셈

ML-KEM에서 기본 연산은 환 \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\)에서의 다항식 곱셈을 포함합니다.

단순 곱셈

차수 \(n-1\)의 두 다항식은 학교 알고리즘으로 \(O(n^2)\) 복잡도로 곱해집니다.

  • \(n = 256\)의 경우: 곱셈당 약 \(256^2 = 65536\)회 곱셈.
  • ML-KEM-768 (\(k=3\))에서 단일 Encaps 연산은 수십 개의 다항식 곱을 필요로 함 → 단순 방법으로는 수백만 회 곱셈.

NTT 사용 시

복잡도가 \(O(n \log n)\)으로 낮아집니다:

\[ 256 \cdot 8 = 2048 \text{ 연산/곱} \]

속도 향상: ~32배. 최적화된 하드웨어에서 ML-KEM-768은 1ms 미만이 소요됩니다.

7.2 푸리에 변환과 DFT

컨볼루션 정리

푸리에 변환은 컨볼루션(다항식 곱셈과 같은)을 점별 곱셈으로 변환합니다:

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

절차:

  1. \(\hat{f} = \text{DFT}(f)\)와 \(\hat{g} = \text{DFT}(g)\) 계산
  2. 점별 곱셈: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. 역변환: \(h = \text{DFT}^{-1}(\hat{h})\)

DFT와 DFT-1이 \(O(n \log n)\) (FFT를 통해)이면, 전체 곱셈은 \(O(n \log n)\)입니다.

고속 푸리에 변환 (FFT)

Cooley-Tukey 알고리즘(1965)은 재귀적 구조를 활용하여 DFT를 계산합니다:

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{짝수}}], \; \text{DFT}[f_{\text{홀수}}]\right) \text{ with twiddle factors} \]

문제: 표준 FFT는 복소수(부동소수점)를 사용하여 반올림 오차와 비일정 시간을 유발하므로 암호화에 부적합합니다.

7.3 NTT: 모듈러 세계의 DFT

아이디어

NTT(수론적 변환)는 \(\mathbb{C}\) 대신 \(\mathbb{Z}_q\)에 적용된 DFT입니다. 복소 단위근 \(e^{2\pi i k/n}\) 대신 \(\mathbb{Z}_q\)의 원시 단위근을 사용합니다.

모듈로 q의 원시 단위근

\(\omega \in \mathbb{Z}_q\)가 원시 \(n\)차 단위근이면:

\[ \omega^n \equiv 1 \pmod{q} \quad \text{and} \quad \omega^k \not\equiv 1 \pmod{q} \text{ for } 0 < k < n \]

필요 조건: \(n \mid (q-1)\) (\(n\)이 \(q-1\)을 나누어야 함).

ML-KEM에서:

  • \(q = 3329\), \(n = 256\)
  • 확인: \(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • 따라서 모듈로 3329의 256차 단위근이 존재함.
  • FIPS 203에서 사용되는 원시근: \(\omega = 17\) (\(17^{128} \equiv -1 \pmod{3329}\)이므로, 부호 교대 NTT에 사용되는 근은 \(\zeta = 17\)).

NTT 정의

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

역 NTT:

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

여기서 \(n^{-1} = 256^{-1} \bmod 3329 = 3303\).

핵심 속성

  • 정확함: 반올림 오차 없음, 모든 연산이 \(\mathbb{Z}_q\)에서 수행됨
  • 효율적: FFT처럼 \(O(n \log n)\)
  • 일정 시간: 비밀 데이터에 대한 분기 없이 구현 가능 (부채널 공격 방어)

7.4 ML-KEM의 NTT

부호 교대 NTT

ML-KEM에서 축소는 \(X^n - 1\)(순환)이 아닌 \(X^n + 1\)(부호 교대) 모듈로입니다. 부호 교대 컨볼루션에서 "감긴" 항들은 부호가 바뀝니다. 이는 조정된 트위들 팩터를 가진 고전적 NTT의 변형이 필요합니다.

FIPS 203의 NTT는 \(\zeta = 17\)의 거듭제곱으로 사전 비틀림을 적용합니다:

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{고전적 NTT 이전} \]

NTT 영역의 ML-KEM 연산

일단 변환되면, 다항식은 NTT 영역에 존재합니다. 연산이 기본적으로 단순해집니다:

연산 NTT 영역에서
곱셈 \(f \cdot g\) 각 \(i\)에 대해 \(\hat{f}_i \cdot \hat{g}_i\)
덧셈 \(f + g\) 각 \(i\)에 대해 \(\hat{f}_i + \hat{g}_i\)
행렬-벡터 곱 \(A \cdot s\) \(k^2\) 점별 곱과 \(k^2\) 점별 합

공개 키 \(A\)는 NTT 영역에서 생성 및 저장되어 매번 NTT를 다시 계산하지 않습니다.

전체 KeyGen 흐름

시드
  │
  ├──► SHAKE128 ──► A_hat (이미 NTT 상태)
  │
  └──► 이항 샘플링 ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          공개 키 (t_hat)

출력 t_hat은 공개 키입니다(NTT 영역 상태). \(t\)에 대한 역 NTT가 생략됩니다.

7.5 간략화된 수치 예제

\(n = 4\), \(q = 5\), \(\omega = 2\) (5의 4차 단위근: \(2^4 = 16 \equiv 1 \pmod 5\))를 사용합니다.

다항식:

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

f의 NTT:

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

g의 NTT: \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\). \(i=0\)일 때: \(4 \equiv 4\); \(i \neq 0\)일 때: 근의 합 \(= 0\).

점별 곱: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\).

\(\hat{h}\)의 역 NTT: \(f \cdot g \bmod (X^4-1, 5)\)의 곱을 제공합니다.

참고: 이 예제는 \(X^4-1\)(순환) 모듈로 축소를 사용합니다. ML-KEM은 7.4절에 설명된 변형으로 \(X^n+1\)(부호 교대)을 사용합니다.

7.6 구현

Cooley-Tukey NTT 의사코드

def ntt(f, q, omega):
    """
    In-place 반복적 NTT (Cooley-Tukey).
    f: Z_q의 n개 계수 리스트
    q: 소수 모듈로
    omega: mod q의 원시 n차 단위근
    """
    n = len(f)
    # 비트 반전 순열
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # 나비 연산 (butterfly)
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

참조 구현

FIPS 203은 NTT의 정확한 구현과 미리 계산된 근 테이블 \(\zeta^{br(i)}\)(\(br\)은 비트 반전 순열)을 명시합니다.

어셈블리/SIMD 최적화 구현은 다음에서 확인할 수 있습니다:

  • liboqs (AVX2를 사용한 C)
  • pqclean (이식 가능한 C)
  • kyber 참조 구현 (C)
