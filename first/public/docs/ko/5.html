5.1 LWE에서 MLWE로: 동기

고전적 LWE와 그 비용

04 파일에서 표준 LWE를 보았습니다: \(m\)개의 샘플 \((\mathbf{a}_i, b_i)\) (\(\mathbf{a}_i \in \mathbb{Z}_q^n\), \(b_i = \langle \mathbf{a}_i, \mathbf{s} \rangle + e_i\))이 주어지면 \(\mathbf{s}\)를 찾습니다. 이 문제는 어렵지만, 실제 비용이 높습니다:

  • 공개 키(행렬 \(A \in \mathbb{Z}_q^{m \times n}\))의 크기는 \(O(n^2)\)입니다: \(n = 1024\), \(q = 3329\)의 경우 2MB가 넘습니다.
  • 행렬-벡터 곱셈 \(A \cdot \mathbf{s}\)는 \(O(n^2)\) 곱셈이 필요합니다.

RLWE: 너무 경직됨

환-LWE는 연산을 환 \(R_q = \mathbb{Z}_q[X]/(X^n + 1)\)으로 옮깁니다. 단일 다항식 \(a \in R_q\)가 전체 행렬을 대체하여 공개 키를 \(O(n)\)으로 줄입니다.

하지만 RLWE는 매우 특정한 대수 구조를 가지며, 일부 연구자들은 이를 잠재적으로 악용 가능하다고 간주합니다(2024년 현재 알려진 실제 공격은 없음).

MLWE: 최적의 절충안

모듈-LWE는 \(R_q\)의 \(k \times k\) 다항식 행렬을 사용하여 둘을 일반화합니다:

\[ \mathbf{A} \in R_q^{k \times k} \]
  • \(k = 1\): RLWE로 축소
  • \(k \to \infty\) (차수 0 다항식): 고전적 LWE로 축소

매개변수 \(k\)는 \(n\)과 독립적으로 보안과 성능을 조정할 수 있게 합니다.

변형 공개 키 보안 유연성
LWE \(O(n^2)\) 높음 낮음
RLWE \(O(n)\) 중간 낮음
MLWE \(O(k \cdot n)\) \(k\)로 조정 가능 높음

5.2 MLWE의 형식적 정의

작업 공간

매개변수:

  • \(n = 256\): 원분 다항식의 차수
  • \(q = 3329\): 소수 모듈로
  • \(k \in \{2, 3, 4\}\): 모듈 차원
  • \(\chi\): 잡음 분포 (중심 이항 분포 \(B_\eta\))

기저 환은 \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\)입니다.

MLWE 분포

\(\mathbf{s} \in R_q^k\)를 비밀 다항식 벡터라고 하며, 각 계수는 \(\chi\)에서 샘플링됩니다.

MLWE 인스턴스는 쌍입니다:

\[ (\mathbf{A},\; \mathbf{t}) \quad \text{where} \quad \mathbf{A} \stackrel{\$}{\leftarrow} R_q^{k \times k},\quad \mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e} \]

\(\mathbf{s}, \mathbf{e} \stackrel{\$}{\leftarrow} \chi^k\)입니다.

결정적 MLWE 문제

입력: \((\mathbf{A}, \mathbf{t})\) 여기서:

  • \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\) (MLWE 분포), 또는
  • \(\mathbf{t} \stackrel{\$}{\leftarrow} R_q^k\) (균일)

목표: 두 경우를 무시할 수 없는 이점으로 구별합니다.

탐색 MLWE 문제

입력: \((\mathbf{A}, \mathbf{t})\) (\(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\))

목표: \(\mathbf{s}\)를 찾습니다.

Regev의 환원(MLWE에 적용)은 탐색 문제가 결정적 문제와 계산적으로 동등하며, 둘 다 고차원 격자의 GapSVP보다 최소한 어렵다는 것을 증명합니다.

5.3 ML-KEM의 잡음 분포

중심 이항 분포 \(B_\eta\)

ML-KEM에서 잡음은 가우시안이 아닌 중심 이항 분포입니다. \(B_\eta\)의 단일 계수를 샘플링하려면:

  1. \(2\eta\)개의 균일 비트를 샘플링합니다: \(a_1, \ldots, a_\eta, b_1, \ldots, b_\eta \in \{0,1\}\)
  2. \(\sum_{i=1}^{\eta} a_i - \sum_{i=1}^{\eta} b_i\)를 반환합니다

결과는 \([-\eta, \eta]\)의 정수입니다.

η = 2에 대한 확률 분포:

값 확률
\(-2\) \(1/16\)
\(-1\) \(4/16\)
\(0\) \(6/16\)
\(+1\) \(4/16\)
\(+2\) \(1/16\)

왜 진짜 가우시안이 아닌가?

이산 가우시안은 이론적으로 최적이지만, 일정 시간(시간 측정 공격에 내성)으로 샘플링하는 것은 복잡합니다. 중심 이항 분포는:

  • 유한한 지지대 → 극단적 경우 없음
  • 비트 연산만으로 샘플링 → 쉽게 일정 시간 구현 가능
  • 알려진 공격에 대해 가우시안과 통계적으로 구별 불가

ML-KEM의 샘플링 (함수 SamplePolyCBD)

CBD_η(σ, b): 입력: 시드 σ ∈ {0,1}^256, 논스 b ∈ {0,1}^8 출력: 계수가 [-η, η]인 다항식 f ∈ R_q bytes = PRF(σ, b) // SHAKE256, 64η 바이트 생성 for j = 0..255: a = bytes의 비트 합 [2ηj .. 2ηj+η-1] b = bytes의 비트 합 [2ηj+η .. 2ηj+2η-1] f[j] = a - b return f

각 다항식 \(\mathbf{s}[i]\)와 \(\mathbf{e}[i]\)는 다른 논스로 샘플링되어 통계적 독립성을 보장합니다.

5.4 ML-KEM의 샘플링

CBD: 중심 이항 분포

ML-KEM은 작은 오류와 비밀을 생성하기 위해 중심 이항 분포 \(B_\eta\)를 사용합니다. 이 분포는 효율적이며 거부 샘플링이 필요하지 않습니다.

함수 SamplePolyCBD(σ, b, η)

입력: 시드 σ ∈ {0,1}^256, 논스 b, 매개변수 η
출력: 계수가 [-η, η]인 다항식 f ∈ R_q

1. bytes = PRF(σ, b)       // SHAKE256, 64·η 바이트 생성
2. for j = 0 to 255:
     a = sum(bits[2ηj .. 2ηj+η-1])   // 첫 번째 그룹의 1 개수
     b = sum(bits[2ηj+η .. 2ηj+2η-1]) // 두 번째 그룹의 1 개수
     f[j] = a - b                     // 0 중심 차이
3. return f

\(\eta=2\)의 경우 계수는 \(\{-2, -1, 0, 1, 2\}\)에 있습니다. \(\eta=3\)의 경우 \(\{-3, \ldots, 3\}\)에 있습니다.

SampleNTT: 균일 샘플링

공개 행렬 \(\mathbf{A}\)를 생성하려면 \(\mathbb{Z}_q\)의 균일 계수가 필요합니다. SHAKE128의 출력에 대한 거부 샘플링을 사용합니다.

함수 SampleNTT(stream)

입력: XOF(SHAKE128)의 바이트 스트림
출력: [0, q-1]의 균일 계수를 가진 다항식

coefficients = []
while len(coefficients) < 256:
    // 2개의 후보 값을 생성하기 위해 3바이트 읽기
    b0, b1, b2 = next_3_bytes(stream)

    // 비트를 결합하여 두 개의 12비트 수 생성
    d1 = b0 + 256 * (b1 mod 16)
    d2 = floor(b1 / 16) + 16 * b2

    // q(3329)보다 작은 경우만 수락
    if d1 < q:
        coefficients.append(d1)
    if d2 < q and len(coefficients) < 256:
        coefficients.append(d2)

return coefficients

이 방법은 범위를 벗어난 값을 폐기하여 완벽한 균일 분포를 보장합니다.

5.5 난이도: MLWE가 어려운 이유

최악의 경우에서 평균적인 경우로의 환원

LWE/MLWE의 가장 중요한 속성은 최악의 경우에서 평균적인 경우로의 환원입니다:

무시할 수 없는 비율의 무작위 인스턴스에서 MLWE를 해결하는 효율적 알고리즘이 존재한다면, 모든 격자에서 최악의 경우 GapSVP(근사 SVP)를 해결하는 효율적 알고리즘이 존재합니다.

이 환원(Regev 2005, Peikert 2009, Brakerski et al.의 MLWE 적용)은 예외적입니다: 대부분의 암호화 문제는 평균-평균 환원만 가집니다.

실제로: 무작위 인스턴스에서 MLWE를 깨는 것은 최악의 경우 SVP를 해결하는 것만큼 어렵습니다 → 암호화 가정이 매우 견고합니다.

양자가 악용할 수 있는 구조의 부재

쇼어 알고리즘은 소인수분해와 이산 로그 문제의 아벨 군 구조를 악용합니다: QFT가 감지할 수 있는 주기적 군 작용이 존재합니다.

MLWE는 이 구조를 가지지 않습니다:

  • 악용할 주기성이 없음
  • QFT를 적용할 자연스러운 아벨 군이 없음
  • 최고의 양자 알고리즘(양자 걷기 또는 QRAM 기반)은 기껏해야 다항식 가속만 제공하며, 지수적이지 않음

5.6 MLWE에서 PKE로: 구성적 아이디어

MLWE로부터 암호화 시스템을 어떻게 구성할까요? 직관은 우아합니다.

디피-헬만과의 유추

DH에서 공개 키는 \(g^s\)입니다: 계산은 쉽고, 역산은 어렵습니다.
MLWE에서 공개 키는 \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)입니다: 계산은 쉽고, 역산은 어렵습니다.

암호화 방식 (Regev 유형)

KeyGen: \(\mathbf{s}, \mathbf{e} \leftarrow \chi^k \qquad \mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)

공개 키: \((\mathbf{A}, \mathbf{t})\).
개인 키: \(\mathbf{s}\).

Encrypt (메시지 \(m \in \{0,1\}\), \(\mu = m \cdot \lfloor q/2 \rfloor\)로 인코딩):

\[ \mathbf{r}, \mathbf{e}_1 \leftarrow \chi^k, \quad e_2 \leftarrow \chi \]
\[ \mathbf{u} = \mathbf{A}^T\mathbf{r} + \mathbf{e}_1 \qquad v = \mathbf{t}^T\mathbf{r} + e_2 + \mu \]

암호문: \((\mathbf{u}, v)\).

Decrypt: \(w = v - \mathbf{s}^T\mathbf{u}\)

분석:

\[ w = \mathbf{t}^T\mathbf{r} + e_2 + \mu - \mathbf{s}^T\mathbf{u} \]
\[ = (\mathbf{A}\mathbf{s})^T\mathbf{r} + \mathbf{e}^T\mathbf{r} + e_2 + \mu - \mathbf{s}^T(\mathbf{A}^T\mathbf{r} + \mathbf{e}_1) \]
\[ = \underbrace{\mathbf{s}^T\mathbf{A}^T\mathbf{r} - \mathbf{s}^T\mathbf{A}^T\mathbf{r}}_{= 0} + \underbrace{\mathbf{e}^T\mathbf{r} + e_2 - \mathbf{s}^T\mathbf{e}_1}_{\text{작은 잡음}} + \mu \approx \mu \]

잡음이 작음 → 반올림하여 \(\mu\)를 복구하고 따라서 \(m\)을 복구합니다.

다항식 버전 (실제 MLWE)

ML-KEM에서 각 스칼라는 \(R_q\)의 다항식이 되고, 연산은 다항식 곱셈입니다. 메커니즘은 동일하지만 곱셈은 환에서 수행됩니다:

\[ \mathbf{t} = \mathbf{A} \circ \mathbf{s} + \mathbf{e} \in R_q^k \]

여기서 \(\circ\)는 \(R_q\)에서의 곱셈(다항식, NTT로 가속)입니다.

5.7 완전한 수치 예제

장난감 매개변수 사용: \(n = 4\), \(q = 17\), \(k = 2\), 계수는 \(\{-1, 0, 1\}\)의 작은 값.

다항식은 \(R_{17} = \mathbb{Z}_{17}[X]/(X^4+1)\)에 있으므로 차수 \(\leq 3\)입니다.

초기 데이터

공개 행렬 \(\mathbf{A} \in R_{17}^{2 \times 2}\):

\[ \mathbf{A} = \begin{pmatrix} a_{00} & a_{01} \\ a_{10} & a_{11} \end{pmatrix} \]

\(a_{00} = 1 + 2X + 3X^2 + 4X^3\), \(a_{01} = 5 + X + 2X^2\), \(a_{10} = 3 + X^3\), \(a_{11} = 1 + X + X^2 + X^3\)

비밀 \(\mathbf{s} = (s_0, s_1)^T\), \(s_0 = 1 - X\), \(s_1 = X^2\).

오류 \(\mathbf{e} = (e_0, e_1)^T\), \(e_0 = 1\), \(e_1 = -X\).

t = As + e 계산

구성 요소 t0 = a00 s0 + a01 s1 + e0:

\[ a_{00} \cdot s_0 = (1 + 2X + 3X^2 + 4X^3)(1 - X) \]
\[ = 1 - X + 2X - 2X^2 + 3X^2 - 3X^3 + 4X^3 - 4X^4 \]

\(X^4 \equiv -1 \pmod{X^4+1}\)로 축소:

\[ = 1 + X + X^2 + X^3 + 4 = 5 + X + X^2 + X^3 \pmod{17} \]
\[ a_{01} \cdot s_1 = (5 + X + 2X^2)(X^2) = 5X^2 + X^3 + 2X^4 \]
\[ \equiv 5X^2 + X^3 - 2 = -2 + 5X^2 + X^3 \equiv 15 + 5X^2 + X^3 \pmod{17} \]
\[ t_0 = (5 + X + X^2 + X^3) + (15 + 5X^2 + X^3) + 1 \]
\[ = 21 + X + 6X^2 + 2X^3 \equiv 4 + X + 6X^2 + 2X^3 \pmod{17} \]

결과: \(\mathbf{t} = (4 + X + 6X^2 + 2X^3,\ \ldots)^T\) (두 번째 구성 요소는 유사하게 계산).

핵심 관찰

\((\mathbf{A}, \mathbf{t})\)를 보는 공격자는 \((\mathbf{s}, \mathbf{e})\)를 찾아야 합니다. 이 작은 숫자들로도 문제는 이미 쉽지 않습니다: 가우스 소거법을 사용할 수 없고(오류가 선형성을 깨뜨림), 탐색 공간은 ML-KEM의 실제 차원에서 지수적입니다.

5.8 ML-KEM 매개변수가 그러한 이유

\(n = 256\)

  • 2의 거듭제곱이어야 함 (효율적인 NTT를 위해)
  • 다항식 \(X^{256}+1\)은 \(\mathbb{Z}_q\) 위에서 기약이어야 함: \(q \equiv 1 \pmod{512}\)이면 성립
  • \(256\)은 보안과 성능의 균형: \(n = 128\)은 너무 불안전하고, \(n = 512\)는 너무 느림

\(q = 3329\)

  • 소수여야 함 (\(\mathbb{Z}_q\)가 체가 되도록)
  • \(q \equiv 1 \pmod{256}\)을 만족해야 함: \(3329 = 13 \cdot 256 + 1\) ✓
  • 256차 단위근이 존재해야 함: 위 조건에 의해 보장됨
  • 잡음 예산과 호환되는 가장 작은 값이어야 함 (컴팩트한 키를 위해)
  • \(3329\)는 모든 조건을 충족하면서 잡음에 충분한 여유를 가진 소수

\(k \in \{2, 3, 4\}\)

  • \(k = 2\) (ML-KEM-512): NIST 레벨 1, 양자 이전 AES-128에 해당
  • \(k = 3\) (ML-KEM-768): NIST 레벨 3, AES-192에 해당, 일반 용도 권장
  • \(k = 4\) (ML-KEM-1024): NIST 레벨 5, AES-256에 해당, 높은 중요도 시스템용

\(\eta_1, \eta_2 \in \{2, 3\}\)

잡음은 다음과 같아야 합니다:

  • MLWE 문제를 어렵게 만들 만큼 충분히 큼
  • 복호화 실패를 보장하지 않을 만큼 충분히 작음 (잡음 예산)

\(\eta\)를 증가시키면 보안이 증가하지만 복호화 오류 확률도 증가합니다. ML-KEM-768의 \(\eta_1 = 2, \eta_2 = 2\) 값이 최적점입니다.
