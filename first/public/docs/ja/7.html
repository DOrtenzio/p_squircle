07 – NTT（数論変換）

ML-KEM を実用的にするエンジン

7.1 問題：多項式の乗算

ML-KEM では、基本演算は環 \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\) における多項式の乗算を含みます。

ナイーブな乗算

次数 \(n-1\) の 2 つの多項式は、学校で習うアルゴリズムで \(O(n^2)\) の複雑さで乗算されます。

  • \(n = 256\) の場合：1 回の積につき約 \(256^2 = 65536\) 回の乗算。
  • ML-KEM-768（\(k=3\)）では、1 回の Encaps 操作に数十回の多項式積が必要 → ナイーブな方法では数百万回の乗算。

NTT を使用

複雑さが \(O(n \log n)\) に低下します。

\[ 256 \cdot 8 = 2048 \text{ 回の演算/積} \]

高速化： 約 32 倍。最適化されたハードウェアでは、ML-KEM-768 は 1 ms 未満です。

7.2 フーリエ変換と DFT

畳み込み定理

フーリエ変換は畳み込み（多項式の乗算など）を点ごとの積に変換します。

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

手順：

  1. \(\hat{f} = \text{DFT}(f)\) と \(\hat{g} = \text{DFT}(g)\) を計算
  2. 点ごとに乗算：\(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. 逆変換：\(h = \text{DFT}^{-1}(\hat{h})\)

DFT と DFT-1 が \(O(n \log n)\)（FFT による）で計算できる場合、乗算全体は \(O(n \log n)\) になります。

高速フーリエ変換（FFT）

Cooley-Tukey アルゴリズム（1965）は、再帰的構造を利用して DFT を計算します。

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{偶数}}], \; \text{DFT}[f_{\text{奇数}}]\right) \text{ を twiddle factors で結合} \]

問題： 標準的な FFT は複素数（浮動小数点）を使用するため、丸め誤差と非定数時間が発生し、暗号には不適切です。

7.3 NTT：モジュラ世界での DFT

アイデア

NTT（数論変換）は、\(\mathbb{C}\) ではなく \(\mathbb{Z}_q\) に適用された DFT です。複素数の 1 の冪根 \(e^{2\pi i k/n}\) の代わりに、\(\mathbb{Z}_q\) における原始 1 の冪根を使用します。

法 q における原始 1 の冪根

要素 \(\omega \in \mathbb{Z}_q\) は、以下の場合に \(n\) 次の原始 1 の冪根です。

\[ \omega^n \equiv 1 \pmod{q} \quad \text{かつ} \quad 0 < k < n \text{ に対して } \omega^k \not\equiv 1 \pmod{q} \]

必要条件：\(n \mid (q-1)\)（つまり \(n\) が \(q-1\) を割り切ること）。

ML-KEM では：

  • \(q = 3329\)、\(n = 256\)
  • 検証：\(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • したがって、法 3329 における 256 次の 1 の冪根が存在します。
  • FIPS 203 で使用される原始根：\(\omega = 17\)（\(17^{128} \equiv -1 \pmod{3329}\) のため、NTT ネガサイクリックに使用される根は \(\zeta = 17\)）

NTT の定義

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

逆 NTT：

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

ここで \(n^{-1} = 256^{-1} \bmod 3329 = 3303\)。

重要な特性

  • 正確： 丸め誤差なし、すべて \(\mathbb{Z}_q\) 上
  • 効率的： FFT と同様に \(O(n \log n)\)
  • 定数時間： 秘密データに対する分岐なしで実装可能（サイドチャネル耐性）

7.4 ML-KEM における NTT

ネガサイクリック NTT

ML-KEM では、簡約は \(X^n - 1\)（サイクリック）ではなく \(X^n + 1\)（ネガサイクリック）を法として行われます。ネガサイクリック畳み込みでは、「折り返された」項の符号が変わります。これには、調整された twiddle factors を持つ古典的な NTT の変種が必要です。

FIPS 203 の NTT は、\(\zeta = 17\) の冪による前ひねりを適用します。

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{NTT クラシックの前} \]

NTT 領域での ML-KEM 演算

一度変換されると、多項式は NTT 領域に存在します。演算は要素ごとになります。

演算 NTT 領域での処理
乗算 \(f \cdot g\) 各 \(i\) について \(\hat{f}_i \cdot \hat{g}_i\)
加算 \(f + g\) 各 \(i\) について \(\hat{f}_i + \hat{g}_i\)
行列-ベクトル積 \(A \cdot s\) \(k^2\) 回の積と \(k^2\) 回の要素ごとの加算

公開鍵 \(A\) は NTT 領域で生成・保存され、NTT の再計算を回避します。

KeyGen の完全なフロー

シード
  │
  ├──► SHAKE128 ──► A_hat（すでに NTT 領域）
  │
  └──► 二項サンプリング ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          公開鍵（t_hat）

出力 t_hat は公開鍵です（すでに NTT 領域）。\(t\) の NTT-1 は回避されます。

7.5 簡略化した数値例

\(n = 4\)、\(q = 5\)、\(\omega = 2\)（法 5 における 4 次の 1 の冪根：\(2^4 = 16 \equiv 1 \pmod 5\)）を使用します。

多項式：

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

f の NTT：

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

g の NTT： \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\)。\(i=0\) の場合：\(4 \equiv 4\)；\(i \neq 0\) の場合：根の和 \(= 0\)。

要素ごとの積： \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\)。

\(\hat{h}\) の INTT： 積 \(f \cdot g \bmod (X^4-1, 5)\) を与えます。

注意： この例では \(X^4-1\)（サイクリック）による簡約を使用しています。ML-KEM は \(X^n+1\)（ネガサイクリック）を 7.4 節で説明した変種で使用します。

7.6 実装

Cooley-Tukey NTT の擬似コード

def ntt(f, q, omega):
    """
    インプレース反復 NTT（Cooley-Tukey）。
    f: Z_q 上の n 個の係数のリスト
    q: 素数法
    omega: 法 q における原始 n 乗根
    """
    n = len(f)
    # ビット反転順列
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # バタフライ演算
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

リファレンス実装

FIPS 203 は NTT の正確な実装と、事前計算された根 \(\zeta^{br(i)}\) のテーブル（\(br\) はビット反転順列）を規定しています。

アセンブリ/SIMD で最適化された実装は以下で入手可能です。

  • liboqs（AVX2 付き C）
  • pqclean（ポータブル C）
  • kyber リファレンス実装（C）
