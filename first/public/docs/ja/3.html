03 – Shor のアルゴリズム

3.1 量子コンピュータ：必須の基礎

量子ビット vs. 古典ビット

古典ビットは 0 または 1 です。量子ビットは 重ね合わせ状態にあり、\(|0\rangle\) と \(|1\rangle\) の線形結合として表現されます。

\[ |\psi\rangle = \alpha|0\rangle + \beta|1\rangle \qquad |\alpha|^2 + |\beta|^2 = 1 \]

測定前は、量子ビットは「0 でもあり 1 でもある」状態です。測定後は、確率 \(|\alpha|^2\) で 0 に、確率 \(|\beta|^2\) で 1 に収束します。

類推： 空中にあるコインが表と裏を同時に表していると想像してください。見た瞬間にどちらかに決まります。

もつれと干渉

  • もつれ（エンタングルメント）： 2 つの量子ビットは、一方を測定するともう一方が即座に決定されるように相関することができます。
  • 量子干渉： 「間違った」計算経路は相殺的に打ち消され（波が打ち消し合うように）、「正しい」経路は増幅されます。

量子アルゴリズムは干渉を利用して正しい答えを増幅し、誤った答えを抑制します。

量子並列性

\(n\) 個の量子ビットで \(2^n\) 個の状態の重ね合わせを表現できます。しかし測定結果は 1 つの状態だけです → 正しい答えだけが生き残るように干渉を構築するのが鍵です。

3.2 Shor のアルゴリズム

\(n\) を因数分解するアルゴリズムの概要

  1. 入力： 合成数 \(n\)
  2. 初期化： \(1 < a < n\) かつ \(\gcd(a,n)=1\) となるランダムな \(a\) を選択
  3. 量子準備： \(0\) から \(2^k-1\) までの一様な重ね合わせ状態のレジスタを準備
  4. オラクル： \(f(x) = a^x \bmod n\) を並列に（重ね合わせで）計算
  5. QFT： 最初のレジスタに量子フーリエ変換を適用
  6. 測定： レジスタを測定し、周期 \(r\) に関連する値を取得
  7. 古典処理： 連分数アルゴリズムを使用して \(r\) を推定
  8. 検証： \(r\) が偶数で \(a^{r/2} \not\equiv -1 \pmod n\) の場合：
    • \(\gcd(a^{r/2} - 1, n)\) と \(\gcd(a^{r/2} + 1, n)\) を計算
    • これらは \(n\) の非自明な因数です
  9. ループ： 失敗した場合は、新しい \(a\) で手順 2 に戻る

注記： 量子の中核部分（手順 3-5）は、QFT の建設的・破壊的干渉を利用して、関数 \(f(x)\) の周期 \(r\) を多項式時間で見つけます。

3.3 RSA、DH、ECC への影響

スキーム セキュリティの基盤 Shor に脆弱？
RSA 因数分解 はい
DH（\(p\) を法とする） \(\mathbb{Z}_p^*\) での離散対数 はい
ECDH / ECDSA ECDLP（楕円曲線上の離散対数） はい
ML-KEM（MLWE） 格子問題 既知の効率的なアルゴリズムなし
AES-256 擬似ランダム置換 Grover のみ（下記参照）

Shor のアルゴリズムは、アーベル群における周期性の発見として構造化された問題を解決します。因数分解と離散対数（EC 上のものも含む）はまさにこの構造を持っています。格子問題はそうではありません。

3.4 Grover：対称鍵暗号への脅威

Grover のアルゴリズム（1996）は、非構造化探索において二次の高速化を提供します。

  • \(2^k\) 個の可能性から鍵を古典的に見つける：\(O(2^k)\) 回の試行
  • Grover を使用：\(O(2^{k/2})\) 回の試行

実用的な影響：

鍵 古典的セキュリティ 耐量子セキュリティ（Grover）
AES-128 128 ビット 64 ビット → 不十分
AES-256 256 ビット 128 ビット → 依然として安全
SHA-256 256 ビット 128 ビット → 安全
SHA3-256 256 ビット 128 ビット → 安全

このため、NIST は耐量子コンテキストでは AES-256（AES-128 ではない）を推奨しています。

3.5 量子コンピュータの現状（2024–2025）

現在の量子コンピュータは NISQ（Noisy Intermediate-Scale Quantum） と呼ばれる段階にあります。数十から数百の物理量子ビットを持ちますが、エラー率が高いです。

RSA-2048 を Shor のアルゴリズムで破るには以下が必要です。

  • 約 4000 個の完全な論理量子ビット
  • または、量子誤り訂正を備えた約 400 万個の物理量子ビット

現在の最良のシステム（Google Willow、IBM Heron など）は約 100-1000 個の高忠実度物理量子ビットを持ちますが、必要な規模にはまだ遠く及びません。

NIST の見積もり： 暗号学的に意味のある量子コンピュータは 10～15 年以内に登場する可能性があり、両方向に大きな不確実性があります。

3.6 今収穫し、後で復号する（Harvest Now, Decrypt Later）

暗号学的に意味のある量子コンピュータがまだ存在しなくても、今日具体的な脅威が存在します。

攻撃者は今暗号化された通信を収集し（たとえ復号できなくても）、将来十分に強力な量子コンピュータを手に入れたときに復号することができます。

この攻撃は 「Harvest Now, Decrypt Later」（HNDL） または store-now-decrypt-later として知られています。

リスクがあるのは誰か：

  • 長い秘密保持期間を持つ外交・軍事通信
  • 10 年単位の機密性要件を持つ医療・金融・法務データ
  • 産業秘密と知的財産

いつ移行すべきか？

データが、十分に強力な量子コンピュータが登場するまでの年数よりも長く秘密にしておく必要がある場合は、今移行しなければなりません。

これが、NIST が 2024 年に ML-KEM（FIPS 203）を標準化した主な理由であり、NSA、ENISA、ANSSI などの組織が高重要度システムに対して即時移行を推奨している理由です。
