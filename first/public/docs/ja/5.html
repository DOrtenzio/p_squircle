5.1 LWE から MLWE へ：動機

古典的 LWE とそのコスト

ファイル 04 で標準的な LWE を見ました。\(m\) 個のサンプル \((\mathbf{a}_i, b_i)\)（\(\mathbf{a}_i \in \mathbb{Z}_q^n\)、\(b_i = \langle \mathbf{a}_i, \mathbf{s} \rangle + e_i\)）が与えられたとき、\(\mathbf{s}\) を見つける問題です。この問題は難しいですが、実用的なコストが高くなります。

  • 公開鍵（行列 \(A \in \mathbb{Z}_q^{m \times n}\)）のサイズは \(O(n^2)\) です。\(n = 1024\)、\(q = 3329\) の場合、2 MB 以上になります。
  • 行列-ベクトル積 \(A \cdot \mathbf{s}\) は \(O(n^2)\) 回の乗算を要します。

RLWE：硬直しすぎ

Ring-LWE は演算を環 \(R_q = \mathbb{Z}_q[X]/(X^n + 1)\) に移します。単一の多項式 \(a \in R_q\) が行列全体を置き換え、公開鍵を \(O(n)\) に削減します。

しかし RLWE は非常に特殊な代数構造を持ち、一部の研究者はそれが潜在的に対象となり得ると考えています（ただし 2024 年現在、実用的な攻撃は知られていません）。

MLWE：最適な妥協案

Module-LWE は \(R_q\) 上の \(k \times k\) 多項式行列を使用して両方を一般化します。

\[ \mathbf{A} \in R_q^{k \times k} \]
  • \(k = 1\)：RLWE に縮退
  • \(k \to \infty\)（次数 0 の多項式）：古典的 LWE に縮退

パラメータ \(k\) により、\(n\) とは独立にセキュリティとパフォーマンスを調整できます。

変種 公開鍵 セキュリティ 柔軟性
LWE \(O(n^2)\) 高い 低い
RLWE \(O(n)\) 中程度 低い
MLWE \(O(k \cdot n)\) \(k\) で調整可能 高い

5.2 MLWE の形式的定義

作業空間

以下のパラメータを固定します。

  • \(n = 256\)：円分多項式の次数
  • \(q = 3329\)：素数法
  • \(k \in \{2, 3, 4\}\)：モジュール次元
  • \(\chi\)：ノイズ分布（中心二項分布 \(B_\eta\)）

基本環は \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\) です。

MLWE 分布

\(\mathbf{s} \in R_q^k\) を多項式の秘密ベクトルとし、各係数は \(\chi\) からサンプリングされます。

MLWE インスタンス はペアです。

\[ (\mathbf{A},\; \mathbf{t}) \quad \text{ただし} \quad \mathbf{A} \stackrel{\$}{\leftarrow} R_q^{k \times k},\quad \mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e} \]

\(\mathbf{s}, \mathbf{e} \stackrel{\$}{\leftarrow} \chi^k\) とします。

判定型 MLWE 問題

入力： \((\mathbf{A}, \mathbf{t})\)。ここで

  • \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)（MLWE 分布）、または
  • \(\mathbf{t} \stackrel{\$}{\leftarrow} R_q^k\)（一様分布）

目的： 2 つのケースを無視できないアドバンテージで区別すること。

探索型 MLWE 問題

入力： \((\mathbf{A}, \mathbf{t})\)（\(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)）

目的： \(\mathbf{s}\) を見つけること。

Regev の還元（MLWE に適用）は、探索問題と判定問題が計算的に等価であり、両方が高次元格子における GapSVP と少なくとも同程度に困難であることを示しています。

5.3 ML-KEM におけるノイズ分布

中心二項分布 \(B_\eta\)

ML-KEM では、ノイズはガウス分布ではなく中心二項分布です。\(B_\eta\) から単一の係数をサンプリングするには：

  1. \(2\eta\) 個の一様ビットをサンプリング：\(a_1, \ldots, a_\eta, b_1, \ldots, b_\eta \in \{0,1\}\)
  2. \(\sum_{i=1}^{\eta} a_i - \sum_{i=1}^{\eta} b_i\) を返す

結果は \([-\eta, \eta]\) の整数です。

η = 2 の確率分布：

値 確率
\(-2\) \(1/16\)
\(-1\) \(4/16\)
\(0\) \(6/16\)
\(+1\) \(4/16\)
\(+2\) \(1/16\)

なぜ真のガウス分布ではないのか？

離散ガウス分布は理論的には最適ですが、定数時間（タイミング攻撃に耐性）でのサンプリングは複雑です。中心二項分布は：

  • 有限のサポート → 極端なケースがない
  • ビット演算のみでサンプリング可能 → 自明に定数時間
  • 既知の攻撃に対してガウス分布と統計的に区別できない

ML-KEM におけるサンプリング（SamplePolyCBD 関数）

CBD_η(σ, b): 入力：シード σ ∈ {0,1}^256、ノンス b ∈ {0,1}^8 出力：係数が [-η, η] の多項式 f ∈ R_q bytes = PRF(σ, b) // SHAKE256、64η バイトを生成 j = 0..255 に対して： a = bytes の位置 [2ηj .. 2ηj+η-1] のビットの合計 b = bytes の位置 [2ηj+η .. 2ηj+2η-1] のビットの合計 f[j] = a - b f を返す

各多項式 \(\mathbf{s}[i]\) と \(\mathbf{e}[i]\) は異なるノンスでサンプリングされ、統計的独立性が保証されます。

5.4 ML-KEM におけるサンプリング

CBD：中心二項分布

ML-KEM は中心二項分布 \(B_\eta\) を使用して、小さな誤差と秘密を生成します。この分布は効率的で、rejection sampling を必要としません。

SamplePolyCBD(σ, b, η) 関数

入力：シード σ ∈ {0,1}^256、ノンス b、パラメータ η
出力：係数が [-η, η] の多項式 f ∈ R_q

1. bytes = PRF(σ, b)       // SHAKE256、64·η バイトを生成
2. j = 0 から 255 まで：
     a = sum(bits[2ηj .. 2ηj+η-1])   // 最初のグループの 1 をカウント
     b = sum(bits[2ηj+η .. 2ηj+2η-1]) // 2番目のグループの 1 をカウント
     f[j] = a - b                     // 0 を中心とした差
3. f を返す

\(\eta=2\) の場合、係数は \(\{-2, -1, 0, 1, 2\}\) の範囲です。\(\eta=3\) の場合は \(\{-3, \ldots, 3\}\) です。

SampleNTT：一様サンプリング

公開行列 \(\mathbf{A}\) を生成するには、\(\mathbb{Z}_q\) 上の一様係数が必要です。SHAKE128 の出力に対して rejection sampling を使用します。

SampleNTT(stream) 関数

入力：XOF（SHAKE128）からのバイトストリーム
出力：[0, q-1] の一様係数を持つ多項式

coeficientes = []
len(coeficientes) < 256 の間：
    // 3バイト読み込んで2つの候補値を生成
    b0, b1, b2 = next_3_bytes(stream)

    // ビットを組み合わせて2つの12ビット数値を形成
    d1 = b0 + 256 * (b1 mod 16)
    d2 = floor(b1 / 16) + 16 * b2

    // q（3329）より小さい場合のみ受け入れる
    d1 < q の場合：
        coeficientes.append(d1)
    d2 < q かつ len(coeficientes) < 256 の場合：
        coeficientes.append(d2)

coeficientes を返す

この方法は、範囲外の値を破棄することで完全な一様分布を保証します。

5.5 困難性：なぜ MLWE が難しいのか

最悪ケースから平均ケースへの還元

LWE/MLWE の最も重要な特性は、最悪ケースから平均ケースへの還元です。

ランダムなインスタンスの無視できない割合に対して MLWE を解く効率的なアルゴリズムが存在するなら、任意の格子に対して GapSVP（SVP の近似版）を最悪ケースで解く効率的なアルゴリズムが存在します。

この還元（Regev 2005、Peikert 2009 および Brakerski らによる MLWE への適用）は例外的です。ほとんどの暗号問題は平均ケースから平均ケースへの還元しか持ちません。

実際には：ランダムなインスタンスで MLWE を破ることは、最悪ケースで SVP を解くのと同じくらい困難です → 暗号の仮定は非常に強固です。

量子によって悪用可能な構造の欠如

Shor のアルゴリズムは、因数分解や離散対数問題のアーベル群構造を悪用します。そこには QFT が検出できる周期的な群作用が存在します。

MLWE にはこの構造がありません。

  • 悪用可能な周期性がない
  • QFT を適用できる自然なアーベル群がない
  • 最良の量子アルゴリズム（量子ウォークや QRAM に基づく）はせいぜい多項式的な高速化しか提供せず、指数関数的ではない

5.6 MLWE から PKE へ：構成的アイデア

MLWE から暗号システムをどのように構築するのでしょうか？直感はエレガントです。

Diffie-Hellman との類推

DH では、公開鍵は \(g^s\) です。計算は簡単で、逆算は困難です。
MLWE では、公開鍵は \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\) です。計算は簡単で、逆算は困難です。

暗号化スキーム（Regev 型）

KeyGen： \(\mathbf{s}, \mathbf{e} \leftarrow \chi^k \qquad \mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)

公開鍵：\((\mathbf{A}, \mathbf{t})\)
秘密鍵：\(\mathbf{s}\)

暗号化（メッセージ \(m \in \{0,1\}\)、\(\mu = m \cdot \lfloor q/2 \rfloor\) としてエンコード）：

\[ \mathbf{r}, \mathbf{e}_1 \leftarrow \chi^k, \quad e_2 \leftarrow \chi \]
\[ \mathbf{u} = \mathbf{A}^T\mathbf{r} + \mathbf{e}_1 \qquad v = \mathbf{t}^T\mathbf{r} + e_2 + \mu \]

暗号文：\((\mathbf{u}, v)\)

復号： \(w = v - \mathbf{s}^T\mathbf{u}\)

解析：

\[ w = \mathbf{t}^T\mathbf{r} + e_2 + \mu - \mathbf{s}^T\mathbf{u} \]
\[ = (\mathbf{A}\mathbf{s})^T\mathbf{r} + \mathbf{e}^T\mathbf{r} + e_2 + \mu - \mathbf{s}^T(\mathbf{A}^T\mathbf{r} + \mathbf{e}_1) \]
\[ = \underbrace{\mathbf{s}^T\mathbf{A}^T\mathbf{r} - \mathbf{s}^T\mathbf{A}^T\mathbf{r}}_{= 0} + \underbrace{\mathbf{e}^T\mathbf{r} + e_2 - \mathbf{s}^T\mathbf{e}_1}_{\text{小さなノイズ}} + \mu \approx \mu \]

ノイズは小さい → 丸めることで \(\mu\) が回復され、したがって \(m\) が回復されます。

多項式版（実際の MLWE）

ML-KEM では、各スカラーが \(R_q\) 内の多項式に置き換えられ、演算は多項式積となります。メカニズムは同一ですが、乗算は環上で実行されます。

\[ \mathbf{t} = \mathbf{A} \circ \mathbf{s} + \mathbf{e} \in R_q^k \]

ここで \(\circ\) は \(R_q\) 上の乗算（多項式、NTT で高速化）です。

5.7 完全な数値例

おもちゃのパラメータを使用します。\(n = 4\)、\(q = 17\)、\(k = 2\)、係数は \(\{-1, 0, 1\}\) の小さい値です。

多項式は \(R_{17} = \mathbb{Z}_{17}[X]/(X^4+1)\) にあり、次数は \(\leq 3\) です。

初期データ

公開行列 \(\mathbf{A} \in R_{17}^{2 \times 2}\)：

\[ \mathbf{A} = \begin{pmatrix} a_{00} & a_{01} \\ a_{10} & a_{11} \end{pmatrix} \]

\(a_{00} = 1 + 2X + 3X^2 + 4X^3\)、\(a_{01} = 5 + X + 2X^2\)、\(a_{10} = 3 + X^3\)、\(a_{11} = 1 + X + X^2 + X^3\)

秘密 \(\mathbf{s} = (s_0, s_1)^T\)、\(s_0 = 1 - X\)、\(s_1 = X^2\)

誤差 \(\mathbf{e} = (e_0, e_1)^T\)、\(e_0 = 1\)、\(e_1 = -X\)

t = As + e の計算

成分 t0 = a00 s0 + a01 s1 + e0：

\[ a_{00} \cdot s_0 = (1 + 2X + 3X^2 + 4X^3)(1 - X) \]
\[ = 1 - X + 2X - 2X^2 + 3X^2 - 3X^3 + 4X^3 - 4X^4 \]

\(X^4 \equiv -1 \pmod{X^4+1}\) で簡約：

\[ = 1 + X + X^2 + X^3 + 4 = 5 + X + X^2 + X^3 \pmod{17} \]
\[ a_{01} \cdot s_1 = (5 + X + 2X^2)(X^2) = 5X^2 + X^3 + 2X^4 \]
\[ \equiv 5X^2 + X^3 - 2 = -2 + 5X^2 + X^3 \equiv 15 + 5X^2 + X^3 \pmod{17} \]
\[ t_0 = (5 + X + X^2 + X^3) + (15 + 5X^2 + X^3) + 1 \]
\[ = 21 + X + 6X^2 + 2X^3 \equiv 4 + X + 6X^2 + 2X^3 \pmod{17} \]

結果： \(\mathbf{t} = (4 + X + 6X^2 + 2X^3,\ \ldots)^T\)（2番目の成分も同様に計算されます）

重要な観察

\((\mathbf{A}, \mathbf{t})\) を見る攻撃者は \((\mathbf{s}, \mathbf{e})\) を見つけなければなりません。これらの小さな数値でも、問題はもはや自明ではありません。誤差が線形性を壊すため Gauss の消去法を使用できず、探索空間は ML-KEM の実際の次元に対して指数関数的です。

5.8 ML-KEM のパラメータがこうなっている理由

\(n = 256\)

  • 2 のべき乗でなければならない（効率的な NTT のため）
  • 多項式 \(X^{256}+1\) は \(\mathbb{Z}_q\) 上で既約でなければならない：\(q \equiv 1 \pmod{512}\) の場合に成立
  • \(256\) はセキュリティとパフォーマンスのバランスが取れている。\(n = 128\) は安全でなく、\(n = 512\) は遅すぎる

\(q = 3329\)

  • 素数でなければならない（\(\mathbb{Z}_q\) が体であるため）
  • \(q \equiv 1 \pmod{256}\) を満たす必要がある：\(3329 = 13 \cdot 256 + 1\) ✓
  • 256 乗根が存在するような値でなければならない：前の条件で保証される
  • ノイズ予算と互換性のある最小値でなければならない（鍵をコンパクトにするため）
  • \(3329\) は、ノイズに対して十分な余裕を持ってすべての条件を満たす素数

\(k \in \{2, 3, 4\}\)

  • \(k = 2\)（ML-KEM-512）：NIST レベル 1、古典的 AES-128 相当
  • \(k = 3\)（ML-KEM-768）：NIST レベル 3、AES-192 相当、一般的な使用に推奨
  • \(k = 4\)（ML-KEM-1024）：NIST レベル 5、AES-256 相当、高重要度システム向け

\(\eta_1, \eta_2 \in \{2, 3\}\)

ノイズは以下の条件を満たす必要があります。

  • MLWE 問題を困難にするのに十分大きい
  • 復号が失敗しないことを保証するのに十分小さい（ノイズ予算）

\(\eta\) を大きくするとセキュリティは向上しますが、復号エラーの確率も増加します。ML-KEM-768 の \(\eta_1 = 2, \eta_2 = 2\) は最適なポイントです。
