07 – NTT (Number Theoretic Transform)

Le moteur qui rend ML-KEM pratiquement utilisable

7.1 Le problème: multiplier des polynômes

Dans ML-KEM, les opérations fondamentales impliquent des multiplications de polynômes dans l'anneau \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\).

Multiplication naïve

Deux polynômes de degré \(n-1\) se multiplient avec l'algorithme scolaire en complexité \(O(n^2)\).

  • Pour \(n = 256\): environ \(256^2 = 65536\) multiplications par produit.
  • Dans ML-KEM-768 (\(k=3\)), une seule opération Encaps nécessite des dizaines de produits polynomiaux → des millions de multiplications avec la méthode naïve.

Avec NTT

La complexité descend à \(O(n \log n)\):

\[ 256 \cdot 8 = 2048 \text{ opérations par produit} \]

Accélération: ~32×. Sur du matériel optimisé, ML-KEM-768 prend moins de 1 ms.

7.2 Transformées de Fourier et DFT

Le théorème de convolution

La transformée de Fourier transforme une convolution (comme la multiplication de polynômes) en un produit ponctuel:

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

Procédure:

  1. Calculer \(\hat{f} = \text{DFT}(f)\) et \(\hat{g} = \text{DFT}(g)\)
  2. Multiplier ponctuellement: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. Transformer inverse: \(h = \text{DFT}^{-1}(\hat{h})\)

Si DFT et DFT-1 coûtent \(O(n \log n)\) (via FFT), toute la multiplication coûte \(O(n \log n)\).

Fast Fourier Transform (FFT)

L'algorithme de Cooley-Tukey (1965) calcule la DFT en exploitant la structure récursive:

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{pairs}}], \; \text{DFT}[f_{\text{impairs}}]\right) \text{ combinés avec des twiddle factors} \]

Le problème: La FFT standard utilise des nombres complexes (virgule flottante), qui introduisent des erreurs d'arrondi et un temps non constant, les rendant inadaptés à la cryptographie.

7.3 NTT: DFT dans le monde modulaire

L'idée

La NTT (Number Theoretic Transform) est la DFT appliquée à \(\mathbb{Z}_q\) au lieu de \(\mathbb{C}\). Au lieu d'utiliser les racines complexes de l'unité \(e^{2\pi i k/n}\), on utilise les racines primitives de l'unité dans \(\mathbb{Z}_q\).

Racines primitives de l'unité modulo q

Un élément \(\omega \in \mathbb{Z}_q\) est une racine \(n\)-ième primitive de l'unité si:

\[ \omega^n \equiv 1 \pmod{q} \quad \text{et} \quad \omega^k \not\equiv 1 \pmod{q} \text{ pour } 0 < k < n \]

Condition nécessaire: \(n \mid (q-1)\) (c'est-à-dire \(n\) doit diviser \(q-1\)).

Dans ML-KEM:

  • \(q = 3329\), \(n = 256\)
  • Vérification: \(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • Il existe donc des racines 256-ièmes de l'unité modulo 3329.
  • La racine primitive utilisée dans FIPS 203: \(\omega = 17\) (puisque \(17^{128} \equiv -1 \pmod{3329}\), la racine utilisée pour la NTT négacyclique est \(\zeta = 17\)).

Définition NTT

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

NTT inverse:

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

où \(n^{-1} = 256^{-1} \bmod 3329 = 3303\).

Propriétés clés

  • Exacte: pas d'erreur d'arrondi, tout est dans \(\mathbb{Z}_q\)
  • Efficace: \(O(n \log n)\) comme la FFT
  • En temps constant: implémentable sans branchement sur des données secrètes (sécurité par canaux auxiliaires)

7.4 NTT dans ML-KEM

NTT négacyclique

Dans ML-KEM, la réduction n'est pas modulo \(X^n - 1\) (cyclique), mais modulo \(X^n + 1\) (négacyclique). Dans la convolution négacyclique, les termes "enroulés" changent de signe. Cela nécessite une variante de la NTT classique avec des facteurs de torsion (twiddle factors) ajustés.

La NTT dans FIPS 203 applique une pré-torsion avec des puissances de \(\zeta = 17\):

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{avant la NTT classique} \]

Opérations ML-KEM dans le domaine NTT

Une fois transformés, les polynômes vivent dans le domaine NTT. Les opérations deviennent élémentaires:

Opération Dans le domaine NTT
Multiplication \(f \cdot g\) \(\hat{f}_i \cdot \hat{g}_i\) pour chaque \(i\)
Somme \(f + g\) \(\hat{f}_i + \hat{g}_i\) pour chaque \(i\)
Produit matrice-vecteur \(A \cdot s\) \(k^2\) produits et \(k^2\) sommes ponctuelles

La clé publique \(A\) est générée et stockée déjà dans le domaine NTT, évitant de recalculer la NTT à chaque fois.

7.5 Exemple numérique simplifié

Utilisons \(n = 4\), \(q = 5\), \(\omega = 2\) (racine 4-ième de 1 modulo 5: \(2^4 = 16 \equiv 1 \pmod 5\)).

Polynômes:

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

NTT de f:

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

NTT de g: \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\). Pour \(i=0\): \(4 \equiv 4\); pour \(i \neq 0\): somme des racines \(= 0\).

Produit ponctuel: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\).

INTT de \(\hat{h}\): donne le produit \(f \cdot g \bmod (X^4-1, 5)\).

Note: cet exemple utilise une réduction modulo \(X^4-1\) (cyclique). ML-KEM utilise \(X^n+1\) (négacyclique) avec la variante décrite dans la section 7.4.

7.6 Implémentation

Pseudocode Cooley-Tukey pour NTT

def ntt(f, q, omega):
    """
    NTT itérative in-place (Cooley-Tukey).
    f: liste de n coefficients dans Z_q
    q: module premier
    omega: racine n-ième primitive de l'unité mod q
    """
    n = len(f)
    # permutation bit-reversal
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # opérations butterfly
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

Implémentation de référence

FIPS 203 spécifie l'implémentation exacte de la NTT et la table des racines précalculées \(\zeta^{br(i)}\) (où \(br\) est la permutation bit-reversal).

Des implémentations optimisées en assembly/SIMD sont disponibles dans:

  • liboqs (C avec AVX2)
  • pqclean (C portable)
  • kyber implémentation de référence (C)
