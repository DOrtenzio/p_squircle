Der Motor, der ML-KEM praktisch nutzbar macht

7.1 Das Problem: Polynome multiplizieren

In ML-KEM betreffen die grundlegenden Operationen Multiplikationen von Polynomen im Ring \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\).

Naive Multiplikation

Zwei Polynome vom Grad \(n-1\) werden mit dem Schulalgorithmus mit einer Komplexität von \(O(n^2)\) multipliziert.

  • Für \(n = 256\): etwa \(256^2 = 65536\) Multiplikationen pro Produkt.
  • In ML-KEM-768 (\(k=3\)) erfordert eine einzige Encaps-Operation Dutzende von Polynomprodukten → mit der naiven Methode Millionen von Multiplikationen.

Mit NTT

Die Komplexität sinkt auf \(O(n \log n)\):

\[ 256 \cdot 8 = 2048 \text{ Operationen pro Produkt} \]

Beschleunigung: ~32×. Auf optimierter Hardware benötigt ML-KEM-768 weniger als 1 ms.

7.2 Fouriertransformationen und DFT

Der Faltungssatz

Die Fouriertransformation wandelt eine Faltung (wie die Polynommultiplikation) in eine punktweise Multiplikation um:

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

Vorgehen:

  1. Berechne \(\hat{f} = \text{DFT}(f)\) und \(\hat{g} = \text{DFT}(g)\)
  2. Multipliziere punktweise: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. Rücktransformieren: \(h = \text{DFT}^{-1}(\hat{h})\)

Wenn DFT und DFT-1 \(O(n \log n)\) kosten (mittels FFT), kostet die gesamte Multiplikation \(O(n \log n)\).

Fast Fourier Transform (FFT)

Der Cooley-Tukey-Algorithmus (1965) berechnet die DFT unter Ausnutzung der rekursiven Struktur:

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{gerade}}], \; \text{DFT}[f_{\text{ungerade}}]\right) \text{ kombiniert mit Twiddle-Faktoren} \]

Das Problem: Die Standard-FFT verwendet komplexe Zahlen (Gleitkomma), was Rundungsfehler und nicht-konstante Laufzeiten einführt, was sie für die Kryptographie ungeeignet macht.

7.3 NTT: DFT in der modularen Welt

Die Idee

Die NTT (Number Theoretic Transform) ist die DFT, angewendet auf \(\mathbb{Z}_q\) anstelle von \(\mathbb{C}\). Anstelle der komplexen Einheitswurzeln \(e^{2\pi i k/n}\) werden primitive Einheitswurzeln in \(\mathbb{Z}_q\) verwendet.

Primitive Einheitswurzeln modulo q

Ein Element \(\omega \in \mathbb{Z}_q\) ist eine primitive \(n\)-te Einheitswurzel, wenn:

\[ \omega^n \equiv 1 \pmod{q} \quad \text{und} \quad \omega^k \not\equiv 1 \pmod{q} \text{ für } 0 < k < n \]

Notwendige Bedingung: \(n \mid (q-1)\) (d.h. \(n\) muss \(q-1\) teilen).

In ML-KEM:

  • \(q = 3329\), \(n = 256\)
  • Prüfung: \(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • Es existieren also primitive 256-te Einheitswurzeln modulo 3329.
  • Die in FIPS 203 verwendete primitive Wurzel: \(\omega = 17\) (da \(17^{128} \equiv -1 \pmod{3329}\), ist die für die negazyklische NTT verwendete Wurzel \(\zeta = 17\)).

Definition der NTT

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

Inverse NTT:

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

wobei \(n^{-1} = 256^{-1} \bmod 3329 = 3303\).

Schlüsseleigenschaften

  • Exakt: keine Rundungsfehler, alles in \(\mathbb{Z}_q\)
  • Effizient: \(O(n \log n)\) wie FFT
  • Zeitkonstant: implementierbar ohne Verzweigungen über geheime Daten (Seitenkanalsicherheit)

7.4 NTT in ML-KEM

Negazyklische NTT

In ML-KEM erfolgt die Reduktion nicht modulo \(X^n - 1\) (zyklisch), sondern modulo \(X^n + 1\) (negazyklisch). Bei der negazyklischen Faltung wechseln die "umgewickelten" Terme das Vorzeichen. Dies erfordert eine Variante der klassischen NTT mit angepassten Twiddle-Faktoren.

Die NTT in FIPS 203 wendet vorab eine Vortorsion mit Potenzen von \(\zeta = 17\) an:

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{vor der klassischen NTT} \]

ML-KEM-Operationen im NTT-Domäne

Einmal transformiert, leben die Polynome in der NTT-Domäne. Die Operationen werden elementar:

Operation In der NTT-Domäne
Multiplikation \(f \cdot g\) \(\hat{f}_i \cdot \hat{g}_i\) für jedes \(i\)
Addition \(f + g\) \(\hat{f}_i + \hat{g}_i\) für jedes \(i\)
Matrix-Vektor-Produkt \(A \cdot s\) \(k^2\) Produkte und \(k^2\) punktweise Additionen

Der öffentliche Schlüssel \(A\) wird bereits in der NTT-Domäne erzeugt und gespeichert, wodurch die Neuberechnung der NTT jedes Mal vermieden wird.

Vollständiger KeyGen-Fluss

Seed 
  │
  ├──► SHAKE128 ──► A_hat (bereits in NTT)
  │
  └──► Binomiale Stichprobennahme ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          Öffentlicher Schlüssel (t_hat)

Die Ausgabe t_hat ist der öffentliche Schlüssel (bereits in NTT). Die NTT-1 für \(t\) wird vermieden.

7.5 Vereinfachtes numerisches Beispiel

Wir verwenden \(n = 4\), \(q = 5\), \(\omega = 2\) (primitive 4-te Einheitswurzel von 1 modulo 5: \(2^4 = 16 \equiv 1 \pmod 5\)).

Polynome:

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

NTT von f:

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

NTT von g: \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\). Für \(i=0\): \(4 \equiv 4\); für \(i \neq 0\): Summe der Wurzeln \(= 0\).

Punktweise Multiplikation: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\).

INTT von \(\hat{h}\): ergibt das Produkt \(f \cdot g \bmod (X^4-1, 5)\).

Hinweis: Dieses Beispiel verwendet Reduktion modulo \(X^4-1\) (zyklisch). ML-KEM verwendet \(X^n+1\) (negazyklisch) mit der in Abschnitt 7.4 beschriebenen Variante.

7.6 Implementierung

Pseudocode Cooley-Tukey für NTT

def ntt(f, q, omega):
    """
    Iterative NTT in-place (Cooley-Tukey).
    f: Liste von n Koeffizienten in Z_q
    q: Primmodul
    omega: primitive n-te Einheitswurzel mod q
    """
    n = len(f)
    # Bit-Reversal-Permutation
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # Butterfly-Operationen
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

Referenzimplementierung

FIPS 203 spezifiziert die genaue NTT-Implementierung und die Tabelle der vorberechneten Wurzeln \(\zeta^{br(i)}\) (wobei \(br\) die Bit-Reversal-Permutation ist).

Optimierte Implementierungen in Assembly/SIMD sind verfügbar in:

  • liboqs (C mit AVX2)
  • pqclean (portables C)
  • kyber Referenzimplementierung (C)
