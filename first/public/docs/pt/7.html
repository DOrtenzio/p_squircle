07 – NTT (Transformada Teórica dos Números)

O motor que torna o ML-KEM praticamente utilizável

7.1 O problema: multiplicar polinómios

Em ML-KEM, as operações fundamentais envolvem multiplicações de polinómios no anel \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\).

Multiplicação ingénua

Dois polinómios de grau \(n-1\) multiplicam-se com o algoritmo escolar com complexidade \(O(n^2)\).

  • Para \(n = 256\): cerca de \(256^2 = 65536\) multiplicações para um único produto.
  • Em ML-KEM-768 (\(k=3\)), uma única operação Encaps requer dezenas de produtos polinomiais → milhões de multiplicações com o método ingénuo.

Com NTT

A complexidade desce para \(O(n \log n)\):

\[ 256 \cdot 8 = 2048 \text{ operações por produto} \]

Aceleração: ~32×. Em hardware otimizado, ML-KEM-768 demora menos de 1 ms.

7.2 Transformadas de Fourier e DFT

O teorema da convolução

A transformada de Fourier transforma uma convolução (como a multiplicação de polinómios) num produto pontual:

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

Procedimento:

  1. Calcular \(\hat{f} = \text{DFT}(f)\) e \(\hat{g} = \text{DFT}(g)\)
  2. Multiplicar pontualmente: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. Transformar inversamente: \(h = \text{DFT}^{-1}(\hat{h})\)

Se DFT e DFT-1 custarem \(O(n \log n)\) (via FFT), toda a multiplicação custa \(O(n \log n)\).

Fast Fourier Transform (FFT)

O algoritmo de Cooley-Tukey (1965) calcula a DFT explorando a estrutura recursiva:

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{pares}}], \; \text{DFT}[f_{\text{ímpares}}]\right) \text{ combinados com factores de rotação} \]

O problema: A FFT padrão usa números complexos (vírgula flutuante), que introduzem erros de arredondamento e tempo não constante, tornando-a inadequada para criptografia.

7.3 NTT: DFT no mundo modular

A ideia

A NTT (Transformada Teórica dos Números) é a DFT aplicada a \(\mathbb{Z}_q\) em vez de \(\mathbb{C}\). Em vez de usar as raízes complexas da unidade \(e^{2\pi i k/n}\), usam-se as raízes primitivas da unidade em \(\mathbb{Z}_q\).

Raízes primitivas da unidade módulo q

Um elemento \(\omega \in \mathbb{Z}_q\) é uma raiz \(n\)-ésima primitiva da unidade se:

\[ \omega^n \equiv 1 \pmod{q} \quad \text{e} \quad \omega^k \not\equiv 1 \pmod{q} \text{ para } 0 < k < n \]

Condição necessária: \(n \mid (q-1)\) (isto é, \(n\) divide \(q-1\)).

Em ML-KEM:

  • \(q = 3329\), \(n = 256\)
  • Verificação: \(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • Existem portanto raízes 256-ésimas da unidade módulo 3329.
  • A raiz primitiva usada em FIPS 203: \(\omega = 17\) (uma vez que \(17^{128} \equiv -1 \pmod{3329}\), a raiz usada para NTT negacíclica é \(\zeta = 17\)).

Definição NTT

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

NTT inversa:

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

onde \(n^{-1} = 256^{-1} \bmod 3329 = 3303\).

Propriedades chave

  • Exata: sem erros de arredondamento, tudo em \(\mathbb{Z}_q\)
  • Eficiente: \(O(n \log n)\) como FFT
  • Tempo constante: implementável sem ramificações em dados secretos (segurança contra ataques de canal lateral)

7.4 NTT em ML-KEM

NTT negacíclica

Em ML-KEM, a redução não é módulo \(X^n - 1\) (cíclica), mas módulo \(X^n + 1\) (negacíclica). Na convolução negacíclica, os termos "enrolados" mudam de sinal. Isto requer uma variante da NTT clássica com factores de rotação ajustados.

A NTT em FIPS 203 aplica uma pré-rotação com potências de \(\zeta = 17\):

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{antes da NTT clássica} \]

Operações ML-KEM no domínio NTT

Uma vez transformados, os polinómios vivem no domínio NTT. As operações tornam-se elementares:

Operação No domínio NTT
Multiplicação \(f \cdot g\) \(\hat{f}_i \cdot \hat{g}_i\) para cada \(i\)
Soma \(f + g\) \(\hat{f}_i + \hat{g}_i\) para cada \(i\)
Produto matriz-vetor \(A \cdot s\) \(k^2\) produtos e \(k^2\) somas pontuais

A chave pública \(A\) é gerada e armazenada já no domínio NTT, evitando recalcular a NTT cada vez.

Fluxo completo de KeyGen

semente 
  │
  ├──► SHAKE128 ──► A_hat (já em NTT)
  │
  └──► Amostragem binomial ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          Chave Pública (t_hat)

A saída t_hat é a chave pública (já em NTT). Evita-se a NTT-1 para \(t\).

7.5 Exemplo numérico simplificado

Usamos \(n = 4\), \(q = 5\), \(\omega = 2\) (raiz 4-ésima de 1 módulo 5: \(2^4 = 16 \equiv 1 \pmod 5\)).

Polinómios:

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

NTT de f:

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

NTT de g: \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\). Para \(i=0\): \(4 \equiv 4\); para \(i \neq 0\): soma de raízes \(= 0\).

Produto pontual: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\).

INTT de \(\hat{h}\): dá o produto \(f \cdot g \bmod (X^4-1, 5)\).

Nota: este exemplo usa redução módulo \(X^4-1\) (cíclica). ML-KEM usa \(X^n+1\) (negacíclica) com a variante descrita na secção 7.4.

7.6 Implementação

Pseudocódigo Cooley-Tukey para NTT

def ntt(f, q, omega):
    """
    NTT iterativa in-place (Cooley-Tukey).
    f: lista de n coeficientes em Z_q
    q: módulo primo
    omega: raiz n-ésima primitiva da unidade mod q
    """
    n = len(f)
    # permutação bit-reversal
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # operações borboleta
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

Implementação de referência

O FIPS 203 especifica a implementação exata da NTT e a tabela de raízes pré-calculadas \(\zeta^{br(i)}\) (onde \(br\) é a permutação bit-reversal).

Implementações otimizadas em assembly/SIMD estão disponíveis em:

  • liboqs (C com AVX2)
  • pqclean (C portável)
  • kyber implementação de referência (C)
