3.1 Computadores quânticos: o essencial

Qubit vs. bit clássico

Um bit clássico é 0 ou 1. Um qubit pode estar em sobreposição: uma combinação linear de \(|0\rangle\) e \(|1\rangle\).

\[ |\psi\rangle = \alpha|0\rangle + \beta|1\rangle \qquad |\alpha|^2 + |\beta|^2 = 1 \]

Antes da medição, o qubit é "simultaneamente 0 e 1". Após a medição, colapsa em 0 (com probabilidade \(|\alpha|^2\)) ou 1 (com probabilidade \(|\beta|^2\)).

Analogia: imagine lançar uma moeda que, enquanto está no ar, representa simultaneamente cara e coroa. Só quando a observa é que se torna uma das duas.

Emaranhamento e interferência

  • Emaranhamento: dois qubits podem estar correlacionados de tal forma que medir um determina instantaneamente o outro.
  • Interferência quântica: os caminhos de cálculo "errados" cancelam-se construtivamente (como ondas que se anulam), enquanto os caminhos "certos" são amplificados.

Os algoritmos quânticos exploram a interferência para amplificar as respostas corretas e suprimir as erradas.

Paralelismo quântico

Com \(n\) qubits, pode-se representar uma sobreposição de \(2^n\) estados simultaneamente. Mas a medição devolve apenas um estado → o truque é construir algoritmos onde as interferências deixam sobreviver apenas a resposta certa.

3.2 O algoritmo de Shor

Esquema do algoritmo para fatorizar \(n\)

  1. Entrada: inteiro composto \(n\)
  2. Inicialização: Escolher \(a\) aleatório tal que \(1 < a < n\) e \(\gcd(a,n)=1\)
  3. Preparação Quântica: Preparar um registo em sobreposição uniforme de \(0\) a \(2^k-1\)
  4. Oracle: Calcular \(f(x) = a^x \bmod n\) em paralelo (sobreposição)
  5. QFT: Aplicar a Transformada de Fourier Quântica ao primeiro registo
  6. Medição: Medir o registo para obter um valor correlacionado com o período \(r\)
  7. Clássico: Usar o algoritmo das frações contínuas para estimar \(r\)
  8. Verificação: Se \(r\) for par e \(a^{r/2} \not\equiv -1 \pmod n\):
    • Calcular \(\gcd(a^{r/2} - 1, n)\) e \(\gcd(a^{r/2} + 1, n)\)
    • Estes são fatores não triviais de \(n\)
  9. Loop: Se falhar, voltar ao passo 2 com um novo \(a\)

Nota: O núcleo quântico (passos 3-5) encontra o período \(r\) da função \(f(x)\) em tempo polinomial, explorando a interferência construtiva/destrutiva da QFT.

3.3 Impacto no RSA, DH, ECC

Esquema Baseia a segurança em Vulnerável a Shor?
RSA Fatorização Sim
DH (mod \(p\)) Logaritmo discreto em \(\mathbb{Z}_p^*\) Sim
ECDH / ECDSA ECDLP (logaritmo discreto em EC) Sim
ML-KEM (MLWE) Problemas de retículos Nenhum algoritmo eficiente conhecido
AES-256 Permutações pseudoaleatórias Apenas Grover (ver abaixo)

Shor resolve qualquer problema estruturado como a procura de periodicidade num grupo abeliano. Fatorização e logaritmo discreto (incluindo em EC) têm exatamente esta estrutura. Os problemas de retículos não.

3.4 Grover: a ameaça à criptografia simétrica

O algoritmo de Grover (1996) oferece uma aceleração quadrática na pesquisa não estruturada:

  • Encontrar uma chave entre \(2^k\) possibilidades classicamente: \(O(2^k)\) tentativas
  • Com Grover: \(O(2^{k/2})\) tentativas

Consequências práticas:

Chave Segurança clássica Segurança pós-quântica (Grover)
AES-128 128 bits 64 bits → insuficiente
AES-256 256 bits 128 bits → ainda seguro
SHA-256 256 bits 128 bits → seguro
SHA3-256 256 bits 128 bits → seguro

Por esta razão, o NIST recomenda AES-256 (não AES-128) no contexto pós-quântico.

3.5 Estado da arte dos computadores quânticos (2024–2025)

Os computadores quânticos atuais são NISQ (Noisy Intermediate-Scale Quantum): têm dezenas-centenas de qubits físicos, mas com alta taxa de erro.

Para quebrar RSA-2048 com Shor, são necessários:

  • ~4000 qubits lógicos perfeitos
  • ou ~4 milhões de qubits físicos com correção de erros quânticos

Os melhores sistemas atuais (Google Willow, IBM Heron, etc.) têm ~100-1000 qubits físicos de alta fidelidade, mas ainda estamos longe da escala necessária.

Estimativa do NIST: computadores quânticos criptograficamente relevantes podem existir dentro de 10–15 anos, com incerteza significativa em ambas as direções.

3.6 Colher agora, decifrar depois

Mesmo que os computadores quânticos não existam ainda de forma criptograficamente relevante, existe uma ameaça concreta hoje:

Um adversário pode colher agora comunicações cifradas (mesmo que não as possa decifrar), e decifrá-las no futuro quando tiver um computador quântico suficientemente potente.

Este ataque é conhecido como "Colher agora, decifrar depois" (Harvest Now, Decrypt Later - HNDL) ou store-now-decrypt-later.

Quem está em risco:

  • Comunicações diplomáticas e militares com longa vida secreta
  • Dados médicos, financeiros, legais com requisitos de confidencialidade decenal
  • Segredos industriais e propriedade intelectual

Quando migrar?

Se os seus dados têm de permanecer secretos por mais anos do que faltam para computadores quânticos suficientemente potentes, tem de migrar agora.

Esta é a principal razão pela qual o NIST padronizou o ML-KEM (FIPS 203) em 2024, e porque organizações como a NSA, ENISA e ANSSI recomendam a migração imediata para sistemas de alta criticidade.
