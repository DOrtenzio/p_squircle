首个后量子标准

FIPS 203: ML‑KEM

FIPS 203 标准化了 ML‑KEM（基于 CRYSTALS‑Kyber），这是一种基于模格子的密钥封装机制。它是 NIST 首个后量子密钥交换标准，旨在抵抗经典攻击和量子攻击。

为什么重要

NIST 流程与现实影响

ML‑KEM 赢得了为期 8 年的 NIST 竞赛，击败了 82 个候选方案。它已集成到 Chrome、Firefox 和 Cloudflare 中。美国联邦机构被要求在 2030 年前采用它（CNSA 2.0），使其成为未来安全的全球标准。
