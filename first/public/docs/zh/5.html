5.1 从 LWE 到 MLWE：动机

经典 LWE 及其成本

在文件 04 中，我们看到了标准 LWE：给定 \(m\) 个样本 \((\mathbf{a}_i, b_i)\)，其中 \(\mathbf{a}_i \in \mathbb{Z}_q^n\) 且 \(b_i = \langle \mathbf{a}_i, \mathbf{s} \rangle + e_i\)，求 \(\mathbf{s}\)。这个问题很困难，但实际成本很高：

  • 公钥（矩阵 \(A \in \mathbb{Z}_q^{m \times n}\)）的大小为 \(O(n^2)\)：对于 \(n = 1024\) 和 \(q = 3329\)，这将是超过 2 MB。
  • 矩阵-向量乘法 \(A \cdot \mathbf{s}\) 的成本为 \(O(n^2)\) 次乘法。

RLWE：过于严格

Ring-LWE 将运算转移到环 \(R_q = \mathbb{Z}_q[X]/(X^n + 1)\) 中。单个多项式 \(a \in R_q\) 取代了整个矩阵，将公钥大小减少到 \(O(n)\)。

但 RLWE 具有非常特殊的代数结构，一些研究人员认为这可能在潜在上可被利用（尽管在 2024 年尚无已知的实际攻击）。

MLWE：最优折衷

Module-LWE 使用 \(R_q\) 中的 \(k \times k\) 多项式矩阵，对两者进行了推广：

\[ \mathbf{A} \in R_q^{k \times k} \]
  • 当 \(k = 1\) 时：退化为 RLWE
  • 当 \(k \to \infty\)（次数为 0 的多项式）时：退化为经典 LWE

参数 \(k\) 允许独立于 \(n\) 校准 安全性和性能。

变体 公钥 安全性 灵活性
LWE \(O(n^2)\) 高 低
RLWE \(O(n)\) 中 低
MLWE \(O(k \cdot n)\) 可通过 \(k\) 调整 高

5.2 MLWE 的形式化定义

工作空间

固定参数：

  • \(n = 256\)：分圆多项式的次数
  • \(q = 3329\)：素数模数
  • \(k \in \{2, 3, 4\}\)：模的维数
  • \(\chi\)：噪声分布（中心二项分布 \(B_\eta\)）

基础环是 \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\)。

MLWE 分布

设 \(\mathbf{s} \in R_q^k\) 是一个秘密多项式向量，每个多项式的系数都从 \(\chi\) 中采样。

一个 MLWE 实例 是一个对：

\[ (\mathbf{A},\; \mathbf{t}) \quad \text{其中} \quad \mathbf{A} \stackrel{\$}{\leftarrow} R_q^{k \times k},\quad \mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e} \]

其中 \(\mathbf{s}, \mathbf{e} \stackrel{\$}{\leftarrow} \chi^k\)。

判定性 MLWE 问题

输入：\((\mathbf{A}, \mathbf{t})\)，其中：

  • 要么 \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)（MLWE 分布），要么
  • \(\mathbf{t} \stackrel{\$}{\leftarrow} R_q^k\) 是均匀的

目标：以不可忽略的优势区分这两种情况。

搜索性 MLWE 问题

输入：\((\mathbf{A}, \mathbf{t})\)，其中 \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)

目标：求 \(\mathbf{s}\)。

Regev 的归约（针对 MLWE 进行了调整）表明，搜索问题在计算上等价于判定问题，并且两者至少和 GapSVP 在高维格上一样困难。

5.3 ML-KEM 中的噪声分布

中心二项分布 \(B_\eta\)

在 ML-KEM 中，噪声不是高斯的，而是中心二项的。要从 \(B_\eta\) 中采样一个系数：

  1. 采样 \(2\eta\) 个均匀比特：\(a_1, \ldots, a_\eta, b_1, \ldots, b_\eta \in \{0,1\}\)
  2. 返回 \(\sum_{i=1}^{\eta} a_i - \sum_{i=1}^{\eta} b_i\)

结果是一个在 \([-\eta, \eta]\) 中的整数。

η = 2 的概率分布：

值 概率
\(-2\) \(1/16\)
\(-1\) \(4/16\)
\(0\) \(6/16\)
\(+1\) \(4/16\)
\(+2\) \(1/16\)

为什么不用真正的高斯分布？

离散高斯在理论上是最优的，但以 恒定时间（抗时间攻击）进行采样很复杂。中心二项分布：

  • 具有有限支集 → 没有极端情况
  • 仅通过位操作进行采样 → 简单恒定时间
  • 对于已知攻击，与高斯分布在统计上不可区分

5.4 ML-KEM 中的采样

CBD：中心二项分布

ML-KEM 使用中心二项分布 \(B_\eta\) 来生成小的误差和秘密。这种分布高效且不需要拒绝采样。

SamplePolyCBD(σ, b, η) 函数

输入：种子 σ ∈ {0,1}^256，随机数 b，参数 η
输出：系数在 [-η, η] 中的多项式 f ∈ R_q

1. bytes = PRF(σ, b)       // SHAKE256，生成 64·η 字节
2. 对于 j = 0 到 255：
     a = sum(bits[2ηj .. 2ηj+η-1])   // 统计第一组中 1 的个数
     b = sum(bits[2ηj+η .. 2ηj+2η-1]) // 统计第二组中 1 的个数
     f[j] = a - b                     // 中心在 0 的差
3. 返回 f

对于 \(\eta=2\)，系数在 \(\{-2, -1, 0, 1, 2\}\) 中。对于 \(\eta=3\)，在 \(\{-3, \ldots, 3\}\) 中。

SampleNTT：均匀采样

为了生成公钥矩阵 \(\mathbf{A}\)，需要 \(\mathbb{Z}_q\) 中的均匀系数。使用对 SHAKE128 输出的 拒绝采样。

SampleNTT(stream) 函数

输入：来自 XOF（SHAKE128）的字节流
输出：系数在 [0, q-1] 中均匀分布的多项式

coefficients = []
当 len(coefficients) < 256：
    // 读取 3 个字节以生成 2 个候选值
    b0, b1, b2 = next_3_bytes(stream)

    // 合并比特以形成两个 12 位数
    d1 = b0 + 256 * (b1 mod 16)
    d2 = floor(b1 / 16) + 16 * b2

    // 仅当小于 q (3329) 时接受
    如果 d1 < q：
        coefficients.append(d1)
    如果 d2 < q 且 len(coefficients) < 256：
        coefficients.append(d2)

返回 coefficients

这种方法保证了完美的均匀分布，丢弃超出范围的值。

5.5 困难性：为什么 MLWE 是困难的

最坏情况到平均情况的归约

LWE/MLWE 最重要的性质是 最坏情况到平均情况的归约：

如果存在一个高效算法能在不可忽略比例的随机实例上解决 MLWE，那么存在一个高效算法能在 任何 格上（在最坏情况下）解决 GapSVP（SVP 的近似版本）。

这种归约（Regev 2005，由 Peikert 2009 和 Brakerski 等人针对 MLWE 进行了调整）是特殊的：大多数密码学问题只有平均情况到平均情况的归约。

在实践中：在随机实例上破解 MLWE 与在最坏情况下解决 SVP 一样困难 → 密码学假设非常强。

缺乏可被量子利用的结构

Shor 算法利用了因数分解和离散对数问题的 阿贝尔群 结构：存在一个周期性的群作用，QFT 可以检测到。

MLWE 不具有这种结构：

  • 没有可利用的周期性
  • 没有可应用 QFT 的自然阿贝尔群
  • 最佳量子算法（基于量子游走或 QRAM）最多提供多项式加速，而非指数加速

5.6 从 MLWE 到 PKE：构造性思想

如何从 MLWE 构建加密系统？直觉很优雅。

与 Diffie-Hellman 的类比

在 DH 中，公钥是 \(g^s\)：容易计算，难以逆推。
在 MLWE 中，公钥是 \(\mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)：容易计算，难以逆推。

加密方案（Regev 类型）

KeyGen：\(\mathbf{s}, \mathbf{e} \leftarrow \chi^k \qquad \mathbf{t} = \mathbf{A}\mathbf{s} + \mathbf{e}\)

公钥：\((\mathbf{A}, \mathbf{t})\)。
私钥：\(\mathbf{s}\)。

Encrypt（消息 \(m \in \{0,1\}\)，编码为 \(\mu = m \cdot \lfloor q/2 \rfloor\)）：

\[ \mathbf{r}, \mathbf{e}_1 \leftarrow \chi^k, \quad e_2 \leftarrow \chi \]
\[ \mathbf{u} = \mathbf{A}^T\mathbf{r} + \mathbf{e}_1 \qquad v = \mathbf{t}^T\mathbf{r} + e_2 + \mu \]

密文：\((\mathbf{u}, v)\)。

Decrypt：\(w = v - \mathbf{s}^T\mathbf{u}\)

分析：

\[ w = \mathbf{t}^T\mathbf{r} + e_2 + \mu - \mathbf{s}^T\mathbf{u} \]
\[ = (\mathbf{A}\mathbf{s})^T\mathbf{r} + \mathbf{e}^T\mathbf{r} + e_2 + \mu - \mathbf{s}^T(\mathbf{A}^T\mathbf{r} + \mathbf{e}_1) \]
\[ = \underbrace{\mathbf{s}^T\mathbf{A}^T\mathbf{r} - \mathbf{s}^T\mathbf{A}^T\mathbf{r}}_{= 0} + \underbrace{\mathbf{e}^T\mathbf{r} + e_2 - \mathbf{s}^T\mathbf{e}_1}_{\text{小噪声}} + \mu \approx \mu \]

噪声很小 → 舍入恢复 \(\mu\)，从而恢复 \(m\)。

多项式版本（实际 MLWE）

在 ML-KEM 中，每个标量都成为 \(R_q\) 中的一个多项式，操作是多项式乘法。机制相同，但乘法在环中执行：

\[ \mathbf{t} = \mathbf{A} \circ \mathbf{s} + \mathbf{e} \in R_q^k \]

其中 \(\circ\) 是 \(R_q\) 中的乘法（多项式，由 NTT 加速）。

5.7 完整数值示例

我们使用玩具参数：\(n = 4\)，\(q = 17\)，\(k = 2\)，系数在 \(\{-1, 0, 1\}\) 中。

多项式在 \(R_{17} = \mathbb{Z}_{17}[X]/(X^4+1)\) 中，因此次数 \(\leq 3\)。

初始数据

公钥矩阵 \(\mathbf{A} \in R_{17}^{2 \times 2}\)：

\[ \mathbf{A} = \begin{pmatrix} a_{00} & a_{01} \\ a_{10} & a_{11} \end{pmatrix} \]

其中 \(a_{00} = 1 + 2X + 3X^2 + 4X^3\)，\(a_{01} = 5 + X + 2X^2\)，\(a_{10} = 3 + X^3\)，\(a_{11} = 1 + X + X^2 + X^3\)

秘密 \(\mathbf{s} = (s_0, s_1)^T\)，其中 \(s_0 = 1 - X\)，\(s_1 = X^2\)。

误差 \(\mathbf{e} = (e_0, e_1)^T\)，其中 \(e_0 = 1\)，\(e_1 = -X\)。

计算 t = As + e

分量 t0 = a00 s0 + a01 s1 + e0：

\[ a_{00} \cdot s_0 = (1 + 2X + 3X^2 + 4X^3)(1 - X) \]
\[ = 1 - X + 2X - 2X^2 + 3X^2 - 3X^3 + 4X^3 - 4X^4 \]

归约 \(X^4 \equiv -1 \pmod{X^4+1}\)：

\[ = 1 + X + X^2 + X^3 + 4 = 5 + X + X^2 + X^3 \pmod{17} \]
\[ a_{01} \cdot s_1 = (5 + X + 2X^2)(X^2) = 5X^2 + X^3 + 2X^4 \]
\[ \equiv 5X^2 + X^3 - 2 = -2 + 5X^2 + X^3 \equiv 15 + 5X^2 + X^3 \pmod{17} \]
\[ t_0 = (5 + X + X^2 + X^3) + (15 + 5X^2 + X^3) + 1 \]
\[ = 21 + X + 6X^2 + 2X^3 \equiv 4 + X + 6X^2 + 2X^3 \pmod{17} \]

结果：\(\mathbf{t} = (4 + X + 6X^2 + 2X^3,\ \ldots)^T\)（第二个分量类似计算）。

关键观察

看到 \((\mathbf{A}, \mathbf{t})\) 的攻击者必须找到 \((\mathbf{s}, \mathbf{e})\)。即使在这些小数字下，问题也不再是平凡的：不能使用高斯消元法（误差破坏了线性），而且搜索空间在 ML-KEM 的实际维度上是指数的。

5.8 为什么 ML-KEM 的参数是这样选择的

\(n = 256\)

  • 必须是 2 的幂（为了高效的 NTT）
  • 多项式 \(X^{256}+1\) 在 \(\mathbb{Z}_q\) 上必须不可约：当 \(q \equiv 1 \pmod{512}\) 时成立
  • \(256\) 平衡了安全性和性能：\(n = 128\) 会太不安全，\(n = 512\) 会太慢

\(q = 3329\)

  • 必须是素数（使 \(\mathbb{Z}_q\) 成为域）
  • 必须满足 \(q \equiv 1 \pmod{256}\)：\(3329 = 13 \cdot 256 + 1\) ✓
  • 必须存在 256 次单位根：由前一个条件保证
  • 必须在噪声预算允许的情况下尽可能小（紧凑密钥）
  • \(3329\) 是满足所有条件且为噪声留有足够余量的素数

\(k \in \{2, 3, 4\}\)

  • \(k = 2\)（ML-KEM-512）：NIST 级别 1，相当于预量子 AES-128
  • \(k = 3\)（ML-KEM-768）：级别 3，相当于 AES-192，推荐通用使用
  • \(k = 4\)（ML-KEM-1024）：级别 5，相当于 AES-256，用于高关键性系统

\(\eta_1, \eta_2 \in \{2, 3\}\)

噪声必须：

  • 足够 大 以使 MLWE 问题变得困难
  • 足够 小 以保证解密不会失败（噪声预算）

增加 \(\eta\) 会提高安全性，但也会增加解密错误的概率。ML-KEM-768 的 \(\eta_1 = 2, \eta_2 = 2\) 是最优点。
