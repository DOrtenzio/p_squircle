2.1 密钥交换问题

Alice 想通过公共信道与 Bob 安全通信。使用 AES 需要共享密钥。他们如何在 Eve（监听一切）不发现的情况下建立共享密钥？

这个问题几个世纪以来一直未解决。解决方案在 1976 年由 Diffie 和 Hellman 提出，1977 年由 Rivest、Shamir 和 Adleman（RSA） 提出。

关键思想：存在 一个方向容易，另一个方向困难 的数学运算。

容易的运算 困难的运算
两个大素数相乘：\(p \cdot q = n\) 分解 \(n\) 以找到 \(p\) 和 \(q\)
计算 \(g^x \bmod p\) 给定 \(g^x \bmod p\) 求 \(x\)（离散对数）
椭圆曲线点加 \(k\) 次：\(kP\) 给定 \(kP\) 求 \(k\)（ECDLP）

2.2 RSA

密钥生成

  1. 选择两个大素数 \(p\) 和 \(q\)（通常各 2048+ 位）
  2. 计算 \(n = p \cdot q\)
  3. 计算 \(\phi(n) = (p-1)(q-1)\)
  4. 选择 \(e\) 使得 \(\gcd(e, \phi(n)) = 1\)（通常 \(e = 65537\)）
  5. 计算 \(d = e^{-1} \bmod \phi(n)\)

公钥：\((n, e)\)
私钥：\((n, d)\)
\(p\)、\(q\)、\(\phi(n)\) 必须销毁。

加密与解密

\[ C = M^e \bmod n \]
\[ M = C^d \bmod n \]

为什么有效：根据欧拉定理，\(M^{\phi(n)} \equiv 1 \pmod{n}\)，因此 \(M^{ed} = M^{1 + k\phi(n)} \equiv M \pmod{n}\)。

数值示例（使用小数字，仅用于教学）

\(p = 61, \quad q = 53, \quad n = 3233\)

\(\phi(n) = 60 \cdot 52 = 3120\)

\(e = 17, \quad d = 2753 \quad \text{（因为 } 17 \cdot 2753 \equiv 1 \pmod{3120}\text{）}\)

加密 \(M = 65\)：

\(C = 65^{17} \bmod 3233 = 2790\)

解密：

\(M = 2790^{2753} \bmod 3233 = 65 \quad \checkmark\)

RSA 作为 KEM

RSA-KEM（简化版）：

  1. Bob 随机生成 \(r \leftarrow \{1, \ldots, n-1\}\)
  2. \(C = r^e \bmod n\)
  3. \(K = H(r)\)（对称密钥）
  4. 将 \(C\) 发送给 Alice
  5. Alice 计算 \(r = C^d \bmod n\)，然后 \(K = H(r)\)

2.3 Diffie-Hellman（DH）

协议

公共参数：大素数 \(p\) 和 \(\mathbb{Z}_p^*\) 的生成元 \(g\)。

Alice
  1. 选择秘密 \(a\)
  2. 计算 \(A = g^a \bmod p\)
A → ← B
Bob
  1. 选择秘密 \(b\)
  2. 计算 \(B = g^b \bmod p\)
\[ \begin{aligned} \text{Alice 计算： } & K = B^a \bmod p = (g^b)^a = g^{ab} \bmod p \\ \text{Bob 计算： } & K = A^b \bmod p = (g^a)^b = g^{ab} \bmod p \end{aligned} \]

结果：双方共享相同的秘密密钥 \(K\)。Eve 只能看到 \(A\) 和 \(B\)，如果不解决离散对数问题，无法计算 \(K\)。

2.4 椭圆曲线密码学（ECDH）

ECDH 是 DH 在椭圆曲线上的类比。它在 TLS 1.3 中与 X25519 曲线一起使用。

Alice
  1. 选择秘密 \(a\)
  2. 计算 \(A = a \cdot G\)
A → ← B
Bob
  1. 选择秘密 \(b\)
  2. 计算 \(B = b \cdot G\)
\[ \begin{aligned} \text{Alice 计算： } & K = a \cdot B = a(b \cdot G) = ab \cdot G \\ \text{Bob 计算： } & K = b \cdot A = b(a \cdot G) = ba \cdot G \end{aligned} \]

其中 \(G\) 是曲线的生成点。安全性基于 ECDLP（椭圆曲线离散对数问题）的困难性。

2.4 椭圆曲线密码学（ECC）

什么是椭圆曲线

在 \(\mathbb{Z}_p\) 上的 椭圆曲线 是满足以下方程的 \((x, y)\) 点的集合：

\[ y^2 \equiv x^3 + ax + b \pmod{p} \]

加上一个特殊点 \(\mathcal{O}\)，称为 无穷远点。

在这些点上定义了具有群性质的 加法 运算。

标量乘法

给定点的加法，定义 标量乘法：

\(kP = P + P + \cdots + P \quad（k \text{ 次}）\)

从 \(P\) 和 \(k\) 计算 \(kP\) 很容易（\(O(\log k)\) 次操作）。反问题——从 \(P\) 和 \(kP\) 求 \(k\)——是 椭圆曲线离散对数问题（ECDLP），在计算上很困难。

ECC 相对于 RSA/DH 的优势

等效安全性 RSA/DH（n/p 的位数） ECC（密钥位数）
80 位 1024 160
128 位 3072 256
256 位 15360 512

在相同安全性下，ECC 提供 更小的密钥 → 更高效。

ECDH（椭圆曲线 Diffie-Hellman）

Alice Bob | | | 选择秘密 a | 选择秘密 b | A = aG | B = bG | | | ------------ A ------------->| | | | <------------ B -------------| | | | K = aB = abG | K = bA = abG | | | ✓ 共享密钥 K |

ECDH 在 TLS 1.3 中与 X25519 曲线（Bernstein 的 curve25519）一起使用。

2.5 经典安全与量子限制

对抗经典计算机

RSA 和 ECC 所依赖的问题对于经典计算机来说是 亚指数 的（不是纯指数）。

最佳的经典因数分解算法是 通用数域筛法（GNFS）：

\[ O\!\left(\exp\!\left(\left(\frac{64}{9}\right)^{1/3} (\ln n)^{1/3} (\ln \ln n)^{2/3}\right)\right) \]

对于 2048 位的 \(n\)，这需要天文数字般长的时间 → 实际上安全。

对抗量子计算机：Shor 算法

1994 年，Peter Shor 证明量子计算机可以：

  • 在 \(O((\log n)^3)\) 时间内 分解 \(n\)
  • 在 \(O((\log p)^3)\) 时间内 解决 DLP
  • 在 \(O((\log p)^3)\) 时间内 解决 ECDLP

拥有足够量子比特的量子计算机将在 数小时或数天内 破解 RSA-2048。

Shor 算法的详细分析见文件 03 – Shor 算法。

答案：后量子密码学

为了在量子时代继续拥有安全的非对称密码学，需要 没有 已知高效量子算法的数学问题。

ML-KEM 所基于的格问题满足这一要求：已知的最佳量子算法与经典算法相比最多只能提供适度的加速。
