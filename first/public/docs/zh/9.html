9.1 安全模型

IND-CPA（选择明文攻击下的不可区分性）

在该模型中，攻击者：

  1. 接收公钥 \(ek\)
  2. 选择两条消息 \(m_0, m_1\)
  3. 接收其中一条的密文（随机选择）
  4. 必须猜测哪条消息被加密了

方案是安全的，如果：\(\Pr[\text{猜对}] \leq 1/2 + \text{negl}(\lambda)\)。

K-PKE（基础加密组件）在 MLWE 假设下是 IND-CPA 的。

IND-CCA2（自适应选择密文攻击下的不可区分性）

与 CPA 类似，但攻击者还可以在任意密文（挑战密文除外）上查询解密预言机。这个模型捕捉了真实攻击（如 Bleichenbacher），其中主动攻击者发送特制消息并观察响应。

ML-KEM 是 IND-CCA2 的。这是 TLS 或 SSH 等实际协议中对安全 KEM 所要求的级别。

ROM vs. QROM

安全性证明使用哈希函数的理想化模型：

  • ROM（随机预言机模型）：哈希是完美的随机预言机。
  • QROM（量子随机预言机模型）：量子攻击者可以在叠加态中查询预言机。

ML-KEM 中使用的 FO（Fujisaki-Okamoto）变换的现代证明保证了 QROM 中的安全性，这对于对抗量子攻击者是必要的。

9.2 如何衡量 MLWE 的困难性

安全性作为攻击成本

没有绝对证据证明 MLWE 是困难的。安全性是通过计算已知最佳攻击算法的成本来估计的。 \(\lambda\) 位安全性意味着攻击大约需要 \(2^\lambda\) 次操作。

参数

困难性取决于：

  • \(n = 256\)（多项式维数，固定）
  • \(k \in \{2, 3, 4\}\)（模的维数）
  • \(q = 3329\)（素数模数）
  • \(\eta \in \{2, 3\}\)（噪声幅度）

格估计器

标准工具是 Albrecht 等人的 Lattice Estimator。对于 ML-KEM-768：

攻击 估计成本（位）
原始攻击（BKZ） ~178 位
对偶攻击 ~175 位
组合攻击 > 200 位

与 128 位经典/量子目标的比较，安全裕度很大。

9.3 针对格的主要攻击

BKZ（Block Korkine-Zolotarev）

这是寻找短向量的最佳通用算法。它将格分成大小为 \(\beta\) 的块，并在局部解决 SVP。复杂度：\(2^{O(\beta \log \beta)}\)。对于 ML-KEM-768，\(\beta \approx 430\)。

原始攻击（uSVP）

将 MLWE 归约到包含公钥和密文的扩展格中的短向量问题。秘密向量 \((\mathbf{s}, \mathbf{e}, -1)\) 成为一个短向量，BKZ 试图找到它。

对偶攻击

利用对偶格通过统计方法区分 MLWE 样本和均匀样本。在对偶格中构造许多短向量以执行区分器。

选择 q = 3329

由于是素数且没有特殊的代数结构，它防止了特定的代数攻击。没有可以利用的小因子或简单关系。

9.4 NIST 安全级别

NIST 定义了 5 个级别。ML-KEM 覆盖级别 1、3 和 5：

方案 NIST 级别 经典安全性 量子安全性
ML-KEM-512 1（AES-128） ~118 位 ~100 位
ML-KEM-768 3（AES-192） ~178 位 ~164 位
ML-KEM-1024 5（AES-256） ~230 位 ~218 位

建议：ML-KEM-768 为大多数用途提供了最佳的安全/性能平衡。ML-KEM-1024 保留给极高关键性的系统。

9.5 与其他 PQC 方案的比较

标准化的后量子 KEM（NIST 2024）

方案 数学基础 公钥 密文
ML-KEM-768 MLWE（格） 1184 B 1088 B
BIKE 纠错码 ~1541 B ~1573 B
HQC 纠错码 ~2249 B ~4522 B
Classic McEliece Goppa 码 ~261 KB 128 B

与经典密码学的比较

方案 公钥 量子安全性
RSA-3072 384 B ❌ 易受攻击
ECDH X25519 32 B ❌ 易受攻击
ML-KEM-768 1184 B ✅ 164+ 位

主要成本是更大的尺寸（与 ECDH 相比约 37×），但对于现代 TLS 握手来说仍然是可接受的。

9.6 侧信道攻击与安全实现

正确的实现可能通过执行时间（时间攻击）或功耗泄露信息而变得脆弱。

恒定时间（Constant-Time - CT）

所有操作必须具有与秘密数据无关的恒定时间。Decaps 中的关键示例：

// 不安全（可变时间）：
if (memcmp(c, c_prime, len) == 0) { 
    K = K_good; 
} else { 
    K = K_reject; 
}

// 安全（恒定时间）：
uint8_t mask = ct_memcmp(c, c_prime, len); // 相等为 0xFF，不同为 0x00
K = ct_select(mask, K_good, K_reject);     // 无分支的 CT 选择

ML-KEM 中 CT 的关键区域

  • \(B_\eta\) 采样：无条件分支的位加法。
  • NTT：蝶形运算必须始终执行，即使结果不变。
  • 密文验证：使用 ct_memcmp。

参考实现

  • pqclean：可移植的 CT 实现。
  • liboqs：具有已验证 CT 属性的 AVX2 优化。
