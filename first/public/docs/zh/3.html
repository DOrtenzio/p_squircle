3.1 量子计算机：基础知识

量子比特 vs. 经典比特

经典比特是 0 或 1。量子比特 可以处于 叠加态：\(|0\rangle\) 和 \(|1\rangle\) 的线性组合。

\[ |\psi\rangle = \alpha|0\rangle + \beta|1\rangle \qquad |\alpha|^2 + |\beta|^2 = 1 \]

在测量之前，量子比特"既是 0 又是 1"。测量后，它坍缩为 0（概率 \(|\alpha|^2\)）或 1（概率 \(|\beta|^2\)）。

类比：想象一枚在空中旋转的硬币，同时代表正面和反面。只有当你观察它时，它才变成其中之一。

纠缠与干涉

  • 纠缠：两个量子比特可以相互关联，使得测量一个立即确定另一个。
  • 量子干涉："错误"的计算路径相消干涉（如波相互抵消），而"正确"的路径被放大。

量子算法利用干涉来放大正确答案并抑制错误答案。

量子并行性

使用 \(n\) 个量子比特，可以同时表示 \(2^n\) 个状态的叠加。但测量只返回一个状态 → 关键在于构建算法，使干涉只让正确答案存活。

3.2 Shor 算法

分解 \(n\) 的算法框架

  1. 输入：合数 \(n\)
  2. 初始化：选择随机 \(a\)，使得 \(1 < a < n\) 且 \(\gcd(a,n)=1\)
  3. 量子准备：准备从 \(0\) 到 \(2^k-1\) 的均匀叠加态寄存器
  4. Oracle：并行计算 \(f(x) = a^x \bmod n\)（在叠加态中）
  5. QFT：对第一个寄存器应用量子傅里叶变换
  6. 测量：测量寄存器以获得与周期 \(r\) 相关的值
  7. 经典：使用连分数算法估计 \(r\)
  8. 验证：如果 \(r\) 是偶数且 \(a^{r/2} \not\equiv -1 \pmod n\)：
    • 计算 \(\gcd(a^{r/2} - 1, n)\) 和 \(\gcd(a^{r/2} + 1, n)\)
    • 这些是 \(n\) 的非平凡因子
  9. 循环：如果失败，返回步骤 2 并选择新的 \(a\)

注意：量子核心（步骤 3-5）利用 QFT 的相长/相消干涉，在多项式时间内找到函数 \(f(x)\) 的周期 \(r\)。

ECDH / ECDSA ECDLP（椭圆曲线离散对数） 是

Shor 解决了任何具有阿贝尔群周期性结构的结构化问题。因数分解和离散对数（包括 EC 上的）恰好具有这种结构。格问题则没有。

3.4 Grover：对对称加密的威胁

Grover 算法（1996）在非结构化搜索中提供 二次 加速：

  • 在 \(2^k\) 种可能性中经典搜索密钥：\(O(2^k)\) 次尝试
  • 使用 Grover：\(O(2^{k/2})\) 次尝试

实际影响：

密钥 经典安全性 后量子安全性（Grover）
AES-128 128 位 64 位 → 不足
AES-256 256 位 128 位 → 仍然安全
SHA-256 256 位 128 位 → 安全
SHA3-256 256 位 128 位 → 安全

因此，NIST 在后量子背景下推荐 AES-256（而非 AES-128）。

3.5 量子计算机的现状（2024–2025）

当前的量子计算机属于 NISQ（嘈杂中等规模量子） 时代：它们有数十到数百个物理量子比特，但错误率较高。

使用 Shor 算法破解 RSA-2048 需要：

  • ~4000 个完美的逻辑量子比特
  • 或 ~400 万个带量子纠错的物理量子比特

目前最好的系统（Google Willow、IBM Heron 等）拥有约 100-1000 个高保真物理量子比特，但我们离所需规模还很远。

NIST 估计：具有密码学意义的量子计算机可能在 10–15 年内出现，但存在很大的不确定性。

3.6 现在收集，以后解密

即使量子计算机尚 未 以密码学相关形式存在，今天 也存在具体的威胁：

攻击者可以 现在收集 加密通信（即使无法解密），并在 未来 拥有足够强大的量子计算机时 解密 它们。

这种攻击被称为 "现在收集，以后解密"（Harvest Now, Decrypt Later - HNDL） 或 store-now-decrypt-later。

谁面临风险：

  • 具有长期保密要求的外交和军事通信
  • 需要数十年保密性的医疗、金融、法律数据
  • 工业机密和知识产权

何时迁移？

如果您的数据需要保密的时间超过了足够强大的量子计算机出现所需的时间，您必须 现在 迁移。

这是 NIST 在 2024 年标准化 ML-KEM（FIPS 203）的主要原因，也是 NSA、ENISA 和 ANSSI 等组织建议高关键性系统立即迁移的原因。
