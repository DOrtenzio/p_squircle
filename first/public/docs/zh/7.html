7.1 问题：多项式乘法

在 ML-KEM 中，基本运算涉及环 \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\) 中的多项式乘法。

朴素乘法

两个次数为 \(n-1\) 的多项式用学校算法相乘，复杂度为 \(O(n^2)\)。

  • 对于 \(n = 256\)：单次乘法约需 \(256^2 = 65536\) 次乘法。
  • 在 ML-KEM-768（\(k=3\)）中，一次 Encaps 操作需要数十次多项式乘法 → 用朴素方法需要数百万次乘法。

使用 NTT

复杂度降至 \(O(n \log n)\)：

\[ 256 \cdot 8 = 2048 \text{ 次操作每次乘法} \]

加速比： ~32×。在优化硬件上，ML-KEM-768 耗时不到 1 毫秒。

7.2 傅里叶变换与 DFT

卷积定理

傅里叶变换将卷积（如多项式乘法）转换为逐点乘法：

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

步骤：

  1. 计算 \(\hat{f} = \text{DFT}(f)\) 和 \(\hat{g} = \text{DFT}(g)\)
  2. 逐点相乘：\(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. 执行逆变换：\(h = \text{DFT}^{-1}(\hat{h})\)

如果 DFT 和 DFT-1 的成本为 \(O(n \log n)\)（通过 FFT），则整个乘法成本为 \(O(n \log n)\)。

快速傅里叶变换（FFT）

Cooley-Tukey 算法（1965）利用递归结构计算 DFT：

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{偶数}}], \; \text{DFT}[f_{\text{奇数}}]\right) \text{ 与旋转因子组合} \]

问题：标准 FFT 使用复数（浮点数），会引入舍入误差和非恒定时间，使其不适合密码学。

7.3 NTT：模世界中的 DFT

思想

NTT（数论变换）是将 DFT 应用于 \(\mathbb{Z}_q\) 而非 \(\mathbb{C}\)。不是使用复单位根 \(e^{2\pi i k/n}\)，而是使用 \(\mathbb{Z}_q\) 中的本原单位根。

模 q 下的本原单位根

元素 \(\omega \in \mathbb{Z}_q\) 是 \(n\) 次本原单位根，如果：

\[ \omega^n \equiv 1 \pmod{q} \quad \text{且} \quad \omega^k \not\equiv 1 \pmod{q} \text{ 对于 } 0 < k < n \]

必要条件：\(n \mid (q-1)\)（即 \(n\) 整除 \(q-1\)）。

在 ML-KEM 中：

  • \(q = 3329\)，\(n = 256\)
  • 验证：\(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • 因此，模 3329 下存在 256 次单位根。
  • FIPS 203 中使用的本原根：\(\omega = 17\)（因为 \(17^{128} \equiv -1 \pmod{3329}\)，用于负循环 NTT 的根为 \(\zeta = 17\)）。

NTT 定义

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

逆 NTT：

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

其中 \(n^{-1} = 256^{-1} \bmod 3329 = 3303\)。

关键性质

  • 精确：无舍入误差，全部在 \(\mathbb{Z}_q\) 中
  • 高效：如同 FFT，\(O(n \log n)\)
  • 恒定时间：可在秘密数据上无分支地实现（抗侧信道攻击）

7.4 ML-KEM 中的 NTT

负循环 NTT

在 ML-KEM 中，归约不是模 \(X^n - 1\)（循环），而是模 \(X^n + 1\)（负循环）。在负循环卷积中，"环绕"的项会改变符号。这需要带有调整后旋转因子的经典 NTT 变体。

FIPS 203 中的 NTT 使用 \(\zeta = 17\) 的幂次进行预旋转：

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{在经典 NTT 之前} \]

NTT 域中的 ML-KEM 操作

一旦转换，多项式就存在于 NTT 域中。操作变得基本：

操作 在 NTT 域中
乘法 \(f \cdot g\) 对于每个 \(i\)，\(\hat{f}_i \cdot \hat{g}_i\)
加法 \(f + g\) 对于每个 \(i\)，\(\hat{f}_i + \hat{g}_i\)
矩阵-向量乘法 \(A \cdot s\) \(k^2\) 次逐点乘法和 \(k^2\) 次逐点加法

公钥 \(A\) 在 NTT 域中生成和存储，避免每次重新计算 NTT。

KeyGen 的完整流程

种子 
  │
  ├──► SHAKE128 ──► A_hat（已在 NTT 中）
  │
  └──► 二项采样 ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          公钥（t_hat）

输出 t_hat 是公钥（已在 NTT 中）。避免了 \(t\) 的 NTT-1。

7.5 简化数值示例

我们使用 \(n = 4\)，\(q = 5\)，\(\omega = 2\)（模 5 下的 4 次单位根：\(2^4 = 16 \equiv 1 \pmod 5\)）。

多项式：

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

f 的 NTT：

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

g 的 NTT：\(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\)。对于 \(i=0\)：\(4 \equiv 4\)；对于 \(i \neq 0\)：根之和 \(= 0\)。

逐点乘法：\(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\)。

\(\hat{h}\) 的逆 NTT：给出乘积 \(f \cdot g \bmod (X^4-1, 5)\)。

注意：此示例使用模 \(X^4-1\)（循环）归约。ML-KEM 使用 \(X^n+1\)（负循环），其变体在第 7.4 节中描述。

7.6 实现

NTT 的 Cooley-Tukey 伪代码

def ntt(f, q, omega):
    """
    原地迭代 NTT（Cooley-Tukey）。
    f：Z_q 中 n 个系数的列表
    q：素数模数
    omega：模 q 下 n 次本原单位根
    """
    n = len(f)
    # 比特反转排列
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # 蝶形运算
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f
