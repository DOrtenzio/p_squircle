7.1 Проблема: умножение полиномов

В ML-KEM основные операции включают умножения полиномов в кольце \(R_q = \mathbb{Z}_q[X]/(X^{256}+1)\).

Наивное умножение

Два полинома степени \(n-1\) умножаются школьным алгоритмом со сложностью \(O(n^2)\).

  • Для \(n = 256\): около \(256^2 = 65536\) умножений для одного произведения.
  • В ML-KEM-768 (\(k=3\)) одна операция Encaps требует десятков полиномиальных умножений → миллионы умножений наивным методом.

С NTT

Сложность снижается до \(O(n \log n)\):

\[ 256 \cdot 8 = 2048 \text{ операций на произведение} \]

Ускорение: ~32×. На оптимизированном оборудовании ML-KEM-768 выполняется менее чем за 1 мс.

7.2 Преобразования Фурье и DFT

Теорема о свёртке

Преобразование Фурье превращает свёртку (как умножение полиномов) в поточечное умножение:

\[ f * g \;\longleftrightarrow\; \hat{f} \cdot \hat{g} \]

Процедура:

  1. Вычислить \(\hat{f} = \text{DFT}(f)\) и \(\hat{g} = \text{DFT}(g)\)
  2. Перемножить поточечно: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i\)
  3. Выполнить обратное преобразование: \(h = \text{DFT}^{-1}(\hat{h})\)

Если DFT и DFT-1 стоят \(O(n \log n)\) (через БПФ), всё умножение стоит \(O(n \log n)\).

Быстрое преобразование Фурье (БПФ)

Алгоритм Кули-Тьюки (1965) вычисляет DFT, используя рекурсивную структуру:

\[ \text{DFT}[f] = \left(\text{DFT}[f_{\text{чётные}}], \; \text{DFT}[f_{\text{нечётные}}]\right) \text{ с коэффициентами поворота} \]

Проблема: Стандартное БПФ использует комплексные числа (с плавающей запятой), что вносит ошибки округления и непостоянное время, делая его непригодным для криптографии.

7.3 NTT: DFT в модульном мире

Идея

NTT (Числовое теоретическое преобразование) — это DFT, применённая к \(\mathbb{Z}_q\) вместо \(\mathbb{C}\). Вместо комплексных корней из единицы \(e^{2\pi i k/n}\) используются примитивные корни из единицы в \(\mathbb{Z}_q\).

Примитивные корни из единицы по модулю q

Элемент \(\omega \in \mathbb{Z}_q\) является примитивным корнем \(n\)-й степени из единицы, если:

\[ \omega^n \equiv 1 \pmod{q} \quad \text{и} \quad \omega^k \not\equiv 1 \pmod{q} \text{ для } 0 < k < n \]

Необходимое условие: \(n \mid (q-1)\) (то есть \(n\) делит \(q-1\)).

В ML-KEM:

  • \(q = 3329\), \(n = 256\)
  • Проверка: \(3329 - 1 = 3328 = 256 \cdot 13\) \(\checkmark\)
  • Следовательно, существуют корни 256-й степени из единицы по модулю 3329.
  • Примитивный корень, используемый в FIPS 203: \(\omega = 17\) (поскольку \(17^{128} \equiv -1 \pmod{3329}\), корень, используемый для негациклического NTT, равен \(\zeta = 17\)).

Определение NTT

\[ \hat{f}_i = \text{NTT}(f)_i = \sum_{j=0}^{n-1} f_j \cdot \omega^{ij} \pmod{q} \]

Обратное NTT:

\[ f_j = \text{NTT}^{-1}(\hat{f})_j = n^{-1} \sum_{i=0}^{n-1} \hat{f}_i \cdot \omega^{-ij} \pmod{q} \]

где \(n^{-1} = 256^{-1} \bmod 3329 = 3303\).

Ключевые свойства

  • Точное: нет ошибок округления, всё в \(\mathbb{Z}_q\)
  • Эффективное: \(O(n \log n)\) как БПФ
  • Постоянное время: может быть реализовано без ветвлений на секретных данных (устойчивость к побочным каналам)

7.4 NTT в ML-KEM

Негациклическое NTT

В ML-KEM редукция выполняется не по модулю \(X^n - 1\) (циклическая), а по модулю \(X^n + 1\) (негациклическая). В негациклической свёртке "завёрнутые" члены меняют знак. Это требует варианта классического NTT со скорректированными коэффициентами поворота.

NTT в FIPS 203 применяет предварительное скручивание со степенями \(\zeta = 17\):

\[ \tilde{f}_j = f_j \cdot \zeta^j \bmod q \quad \text{перед классическим NTT} \]

Операции ML-KEM в домене NTT

После преобразования полиномы находятся в домене NTT. Операции становятся элементарными:

Операция В домене NTT
Умножение \(f \cdot g\) \(\hat{f}_i \cdot \hat{g}_i\) для каждого \(i\)
Сложение \(f + g\) \(\hat{f}_i + \hat{g}_i\) для каждого \(i\)
Умножение матрицы на вектор \(A \cdot s\) \(k^2\) поточечных умножений и \(k^2\) поточечных сложений

Открытый ключ \(A\) генерируется и хранится уже в домене NTT, избегая пересчёта NTT каждый раз.

Полный поток KeyGen

зерно 
  │
  ├──► SHAKE128 ──► A_hat (уже в NTT)
  │
  └──► Биномиальное сэмплирование ──► s, e
         │              │
         ▼              ▼
     s_hat = NTT(s)   e_hat = NTT(e)
         │              │
         └──────┬───────┘
                ▼
     t_hat = A_hat * s_hat + e_hat
                │
                ▼
          Открытый ключ (t_hat)

Выход t_hat — это открытый ключ (уже в NTT). Избегается NTT-1 для \(t\).

7.5 Упрощённый числовой пример

Используем \(n = 4\), \(q = 5\), \(\omega = 2\) (корень 4-й степени из 1 по модулю 5: \(2^4 = 16 \equiv 1 \pmod 5\)).

Полиномы:

\[ f = 1 + 2X + 3X^2 + 4X^3 \quad \Rightarrow \quad \mathbf{f} = (1, 2, 3, 4) \]
\[ g = 1 + X + X^2 + X^3 \quad \Rightarrow \quad \mathbf{g} = (1, 1, 1, 1) \]

NTT от f:

  • \(\hat{f}_0 = 1 + 2 + 3 + 4 = 10 \equiv 0\)
  • \(\hat{f}_1 = 1 + 2 \cdot 2 + 3 \cdot 4 + 4 \cdot 8 = 49 \equiv 4\)
  • \(\hat{f}_2 = 1 + 2 \cdot 4 + 3 \cdot 16 + 4 \cdot 64 = 313 \equiv 3\)
  • \(\hat{f}_3 = 1 + 2 \cdot 8 + 3 \cdot 64 + 4 \cdot 512 = 2257 \equiv 2\)

NTT от g: \(\hat{g}_i = \sum_j \omega^{ij} \pmod 5\). Для \(i=0\): \(4 \equiv 4\); для \(i \neq 0\): сумма корней \(= 0\).

Поточечное умножение: \(\hat{h}_i = \hat{f}_i \cdot \hat{g}_i \pmod 5\).

Обратное NTT от \(\hat{h}\): даёт произведение \(f \cdot g \bmod (X^4-1, 5)\).

Примечание: этот пример использует редукцию по модулю \(X^4-1\) (циклическую). ML-KEM использует \(X^n+1\) (негациклическую) с вариантом, описанным в разделе 7.4.

7.6 Реализация

Псевдокод Кули-Тьюки для NTT

def ntt(f, q, omega):
    """
    Итеративное NTT in-place (Кули-Тьюки).
    f: список из n коэффициентов в Z_q
    q: простой модуль
    omega: примитивный корень n-й степени из единицы mod q
    """
    n = len(f)
    # перестановка bit-reversal
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            f[i], f[j] = f[j], f[i]

    # операции "бабочка"
    length = 2
    while length <= n:
        w = pow(omega, n // length, q)
        for i in range(0, n, length):
            wn = 1
            for k in range(length // 2):
                u = f[i + k]
                v = f[i + k + length // 2] * wn % q
                f[i + k] = (u + v) % q
                f[i + k + length // 2] = (u - v) % q
                wn = wn * w % q
        length <<= 1
    return f

Эталонная реализация

FIPS 203 определяет точную реализацию NTT и предварительно вычисленную таблицу корней \(\zeta^{br(i)}\) (где \(br\) — перестановка битового обращения).

Оптимизированные реализации на ассемблере/SIMD доступны в:

  • liboqs (C с AVX2)
  • pqclean (переносимый C)
  • kyber эталонная реализация (C)
